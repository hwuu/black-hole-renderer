## 0. 术语

| 术语 | 含义 |
|------|------|
| 核心 | 盘中面附近的高斯密度层（等温静力平衡），`density_I` 中的核心吸收与热发射权重为 `ab_c`、`em_c` |
| 大气 | 核心上下按 exp(−\|z\|/H_a) 衰减的稀薄气体，与核心是同一团气体、跟随同一湍流场；`density_I` 中的大气消光、热发射与散射权重为 `ab_a`、`em_a`、`sc_a` |
| 剪切级联 | 主云结构的多尺度噪声：第 k 个八度在 `(ln r, φ)` 中的频率为 `K_k = shear_k0·3^k`（格数 / 单位 ln r），格子按开普勒剪切沿方位方向拉长，长宽比从 `shear_ar_big` 递减到 `shear_ar_small`（`src/v2/shear_cascade.py`） |
| 刚体环带 | 把盘按 ln r 切成宽 `dln_r` 的环带，每条带以其中心半径的开普勒角速度整体转动；相邻两带按 cos² / sin² 混合，每条带有两个周期性重新播种的种子相位（`src/v2/advection.py`）。视频中结构随气体转动、不被卷绕，靠的就是这套机制 |
| 温度湍流、温度起伏 | 温度湍流是本文新增功能的名称（参数前缀 `temp_turb_`）；温度起伏指它产生的物理效果，即采样点温度围绕原值的对数正态变化 |
| 温度倍率 `tf_c` | `density_I` 的第二个返回值：采样点温度 = Page–Thorne 温度 × `tf_c`。核心与大气的热发射共用它 |
| Page–Thorne 温度 | 相对论薄盘的有效温度随半径的分布 T(r)，由 `_page_thorne_temperature` 查表给出 |
| 灰大气温度、`dt_i` | 现有 `tf_c` 的两个因子：随上方光学深度升高的灰大气温度规律，以及随主云明暗变化的大尺度温度调制 `clamp(1 + dt_i·(ĉ − 1), 0.7, 1.3)`（ĉ 为归一化主云密度） |
| 竖直光学深度 τ⊥ | 沿盘面法向穿过核心与大气的光学深度 |
| 源函数 S | 发射系数与消光系数之比；含散射时 S = (1 − ω)·B(T) + ω·J，ω 为散射反照率，J 为入射光的平均强度 |
| 像素足迹 | 一个输出像素在采样点处覆盖的物理尺寸（r_s） |
| 频率钳制 | 程序纹理的抗锯齿方法：比像素足迹还小的频率成分淡出，用其统计均值代替 [1] |
| 掠射 | 视线与盘面夹角很小的观察方式 |
| 间歇性 | 湍流起伏的强度在空间上不均匀：强弱成片出现，有的区域剧烈、有的区域平静 |
| 坐标扭曲 | 把噪声的输入坐标按另一个低频噪声偏移，使特征的排布失去格子的行列规律（domain warping） |
| 高频 | 本文的细节量化指标：8 位灰度图在指定区域内的离散拉普拉斯 `4·a[i,j] − a[i±1,j] − a[i,j±1]` 的标准差，越大细节越多 |

## 1. 问题陈述

### 1.1 现象

close_low 场景中，相机在 r = 22、z = 0.45 处贴着盘面环绕黑洞，画面下方近处的视线仰角约 13°。
近处云层是一片均匀的雾，远处地平线一带和透镜像里则有清楚的纹理。
1080p 静帧中近处（画面第 700–1080 行）的高频为 0.46，地平线一带为 4.04，近处约为远处的 1/9。

### 1.2 目标

1. 近处出现与远处协调的云层细节，细节程度随远近自然变化。
2. 物理自洽：气体场与相机无关；热发射与吸收满足基尔霍夫定律；视频中结构随气体转动。
3. 视频渲染耗时以原型实测（约 1.7 倍，§2.5）为参考。
4. 参数关闭时，所有现有画面逐位不变。

## 2. 分析与调研

> **证据来源**：本章新增的原型数字均为本地实测，设备为 AutoDL RTX 4090（CUDA），分辨率 1920×1080，基线代码为提交 `57834e1`；
> §2.1 的 τ⊥ 引自 `v2_unified_gas_plan.md` §2.3。
> 原型以补丁形式施加在远端临时副本上，补丁、出图脚本与对比图保存在本机 `output/close_low/`，不进仓库；
> 静帧设置为优化级别 1、超采样倍率 2、曝光补偿 +1.5、运镜时刻 t = 30 s、内缘一圈 4 视频秒，另注明者除外。
> 正式实现后按 §7 重新实测。

### 2.1 近处为什么是雾

r = 22 处核心的竖直光学深度 τ⊥ 约 0.7（`v2_unified_gas_plan.md` §2.3 的实测）。近处视线仰角约 13°，
沿视线的光学深度约 0.7 / sin 13° ≈ 3。所以每条近处视线看到的是沿视线约 1 r_s 深度上的加权平均（推断）。

沿深度互不相关的小尺度起伏会被这个平均抹掉，只有对比足够强的结构才能留在画面上。
`v2_unified_gas_plan.md` §2.3 有同样的结论：均匀介质掠射就是雾，云雾感必须来自结构本身。

### 2.2 被否定的做法

| 做法 | 改动 | 近处结果 | 结论 |
|------|------|----------|------|
| A：主云级联向小尺度延伸 | 主云与大气小尺度起伏各加 3 个八度，按像素足迹淡出 | 高频 0.80 → 0.81，像素平均变化 3.1 / 255 | 新八度幅度按逐八度增益 0.6 衰减，弱起伏被视线积分平均掉 |
| A′：近场稀疏团块 | 相机 4–8 r_s 内叠加对数正态团块（强度 σ = 1–2），吸收只按团块倍率的 β 次方调制 | 高频 0.46 → 0.58–1.22，纹理可见 | 画面可用，模型属于特殊处理：气体随相机距离变化，视频中会"沸腾"；β < 1 时热发射与吸收不同源，违背基尔霍夫定律；另起一套噪声，与剪切级联几何不一致；团块不随气体转动 |
| 表面起伏延伸 | 盘面厚度扰动向小尺度延伸 3 个八度，幅度放大到 5 倍 | 像素平均变化 0.70 / 255，高频不变；此时盘面标高的 10% / 90% 分位为原标高的 0.40 / 0.92 | 厚度扰动只改变盘面厚度，柱密度不变。平行平板中掠射视线的光学深度只由柱密度与角度决定，温度又按光学深度计算，所以亮度与厚度无关 |

A 与表面起伏延伸的数据来自两次不同的相机参数（close_low 定稿前后，前一次的完整参数未记录），"改动前"的高频分别为 0.80 与 0.46；
结论只看各自实验内的相对变化，两组绝对值不做交叉比较。A′ 的原型补丁保存在本机 `output/close_low/a_prime_backup/`，作为回退选项。

### 2.3 选型：小尺度温度起伏

A′ 说明对比足够强的小尺度起伏能留在画面上。用户在 A′ 的三档中更偏好 β = 0，即团块只改变发光、不改变遮挡。
这在物理上对应**温度起伏**：密度与吸收系数不变，只有热发射的源函数 B(T) 随温度变化。
热吸收部分满足基尔霍夫关系 j_abs = α_abs·B(T) [2]，α_abs 不变而 T 变化仍满足这一关系；
散射部分的源函数 J 按 §3.6 的简化处理。

温度起伏用很小的幅度就能产生足够的对比。可见光亮度在渲染中按 Y(s·T) 计算（s = `lum_temp_scale` = 1.25），
其局部对数斜率 n = dlnY/dlnT 由 `palette.luminance_log_slope` 算出：T = 3000 / 4000 / 5000 K 时分别为 6.8 / 5.2 / 4.2。
小扰动近似下，10% 的温度起伏带来约 42%–68% 的亮度起伏，足以经受视线积分（推断；实际对比还受频移与积分平均影响）。
颜色也随温度一起变化：热处偏白、冷处偏金。A′ 只改亮度，没有这一点。

湍流中温度起伏的幅度取多少由场景决定。本方案把幅度作为参数，默认关闭（工程判断）。

### 2.4 归一方式：平均通量守恒

温度起伏会抬高平均可见光亮度，因为 Y(T) 是凸函数。原型中按"平均温度守恒"归一的 10% 档，
近处平均灰度从 34.8 升到 42.0。

黑体表面的辐射通量为 σ_SB·T⁴ [2]。本方案以 ⟨T⁴⟩ 守恒作为温度起伏的归一约束（§3.1），
使起伏前后的平均热辐射通量近似不变（工程判断）。这一约束不保证最终像素亮度不变：
渲染还包含频移、有限光学深度、散射与成像链。原型实测 10% 档近处平均灰度为 38.8，
剩下的上升主要来自可见光亮度对温度比 T⁴ 更陡（推断）。

原型（文中记为 A″）与本方案的模型相同，实现上有三处差异，见本节末。

|------|----------|------------|--------------|------------------------------------------|
| 关闭 | 0.46 | 4.04 | 34.8 | 1.13 / 1.13 / 1.34 |
| 温度起伏 10%（平均通量守恒） | 0.64 | 4.05 | 38.8 | 1.89 / 1.94 / 2.26 |

1. 延伸八度的长宽比：原型为 3.3 与 2.5（几何函数的总八度数取 6，长宽比被重新插值）；本方案统一取 `shear_ar_small`（§3.2）。

### 2.6 首版的问题：密恐与规律感（v1.5）

v1.4 实施后，interstellar_skim 120 s 小样（360p）中近处云层是一片大小相近、均匀铺满的斑块，用户反馈"有点密恐、过于有规律"。
对照小样逐帧检查，原因有三（推断）：

| 编号 | 原因 | 表现 |
|------|------|------|
| P1 | 只延伸 2 个八度，幅度比 0.69，两个八度强度接近 | 斑块大小一致 |
| P2 | 起伏强度在全盘相同，没有间歇性 | 到处都在"沸"，像均匀贴图 |
| P3 | 值噪声在格点间插值，格子沿方位方向排列（长宽比 2.5） | 圆斑排成行列，看出规律 |

P1 由 P2、P3 的处理间接缓解（强弱分区后，同尺度斑块不再连片），本版不增加八度（§3.5 的精度上限不变）。

**原型对比**（1080p 视频档：优化级别 2、超采样倍率 1；σ_T = 0.1；skim 路径 t = 44 s 画面下半部第 680–1080 行；
设备与统计口径同本章开头，基线为提交 `ea72b29`）：

| 版本 | 下半部高频 | 积分耗时（s / 帧） | 观感 |
|------|------------|--------------------|------|
| v1.4 | 1.20 | 1.25 | 斑块大小一致、均匀铺满 |
| 间歇性 γ = 1.5 | 1.41 | 1.26 | 强弱成片，均匀铺满感消失 |
| 间歇性 γ = 1.5 + 梯度噪声 | 1.79 | 1.33 | 颗粒感增多 |
| 间歇性 γ = 1.5 + 值噪声扭曲 0.35 格 | 1.59 | 1.78 | 斑块成为不规则丝缕，行列规律基本消失，无颗粒感 |
| 间歇性 γ = 1.5 + 梯度噪声 + 扭曲 0.8 格 | 4.56 | 1.85 | 过碎，像噪点 |

梯度噪声高频能量更多，大幅扭曲又把特征压缩到一格以下、越过了频率钳制，二者都带来颗粒感（推断）。
用户选定"间歇性 γ = 1.5 + 值噪声扭曲 0.35 格"。对比图保存在本机 `output/v2_arts/turb_ab/`，不进仓库。

## 3. 方案设计

### 3.1 模型

符号约定：r 为盘局部柱坐标半径 `√(x_l² + y_l²)`（r_s，x_l、y_l 为盘局部坐标），区别于光线的球半径 |x|；
E 为延伸八度数，e = 0 … E−1。

在温度倍率上乘温度起伏因子：

```
tf_c ← tf_c · f_T
f_T  = exp(σ_l·n_T − 2σ_l²·V)
σ_l  = σ_T·m(ĉ)                      （局部强度，间歇性见 §3.7）
n_T  = Σ_e a_e·w_e·ν_e / N          （单个图案；刚体环带混合见 §3.2）
V    = Σ_e (a_e·w_e)² / Σ_e a_e²
```

| 符号 | 含义 |
|------|------|
| σ_T | 温度起伏强度（无量纲）：局部强度 σ_l 的全盘均方根（§3.7）；`temp_turb_sigma`，0 = 关闭 |
| σ_l | 局部强度：全部 w_e = 1 时该处 ln T 起伏的标准差；频率钳制后局部实际标准差约为 σ_l·√V |
| ν_e | 第 e 个延伸八度的值噪声，零均值，值域 [−1, 1] |
| a_e | 八度幅度 `temp_turb_gain^e`，a_0 = 1 |
| w_e | 足迹钳制与透镜衰减后的权重（§3.3），值域 [0, 1]；八度满足足迹阈值且透镜权重 L = 1 时为 1 |
| N | 全部 w_e = 1 时 `Σ_e a_e·ν_e` 的标准差，构造期在固定网格上标定（见下文"接口"） |
| V | 钳制后 n_T 的方差（推导见下）；全部 w_e = 1 时 V = 1 |

**V 的推导**：设各八度噪声近似独立、方差同为 σ_ν²，则 N² = σ_ν²·Σ_e a_e²，
Var(Σ_e a_e·w_e·ν_e) = σ_ν²·Σ_e (a_e·w_e)²，二者相除 σ_ν² 约去，得 Var(n_T) ≈ V。
N 用实测值，使全部 w_e = 1 时 n_T 的方差精确为 1；V 的公式保证同一情形下 V = 1，二者一致。

**为什么 ⟨f_T⁴⟩ = 1**：给定 σ_l，设 n_T 近似服从均值 0、方差 V 的高斯分布，则
⟨exp(4σ_l·n_T)⟩ = exp(8σ_l²·V)，所以 ⟨f_T⁴⟩ = ⟨exp(4σ_l·n_T − 8σ_l²·V)⟩ = 1。
多个值噪声之和近似高斯，各八度近似独立，这两点是工程近似，由单测检查（§7 第 6 项）。
全部八度淡出时 w_e = 0，于是 n_T = 0、V = 0，f_T 精确为 1，tf_c 与关闭时逐位相同。

v1.4 的均匀强度是特例：`temp_turb_intermittency = 0` 时 m(ĉ) ≡ 1，σ_l = σ_T。

**接口**：`density_I(r, z, phi, t_delay, foot, lens_w)`，新增像素足迹 `foot`（r_s）与透镜权重 `lens_w`（§3.3）。
返回值仍为六元组 `(em_c, tf_c, ab_c, ab_a, em_a, sc_a)`，其中 `tf_c` 已乘 f_T。
开启后 `tf_c` 只保证 > 0，不再落在原有的 [0.7, 1.3·grey_cap] 内；关闭时值域不变。`density_I` 的 docstring 同步更新。
f_T 只改 `tf_c`，不改主云密度、吸收、散射反照率与 `sc_a`。所以核心与大气的热发射都随温度起伏，
大气散射项 `sc_a·scatter_j·S_disk` 不变（S_disk 是下方盘面的平均源函数，§3.6）。
κ 标定调用 `density_I` 时传 `foot = 1`、`lens_w = 0`：全部钳制权重为 0，f_T = 1，标定结果与改动前相同。
N 在 κ 之前标定，不依赖 κ、透镜权重与刚体环相位：在 ln r ∈ [ln r_in, ln r_out] 的 256 个等分中点与
φ ∈ [0, 2π) 的 512 个等分中点组成的网格上（与现有 `low_norm`、`fine_norm` 的标定网格相同），取种子偏移 ox = oz = 0，
竖直坐标 z/r = ζ/100（ζ_ij = ((7i + 13j) mod 17)/17·4 − 2，与 `fine_norm` 相同），使第三个噪声坐标跨越多个格
（值噪声在整数格点平面上的方差偏大，取 z = 0 会使 N 偏大约 17%），
计算单个图案 `q = Σ_e a_e·ν_e` 的总体标准差 `N = std(q)`。所有直接调用 `density_I` 的 kernel 与单测同步改为新签名。

### 3.2 几何与转动

延伸八度沿用剪切级联的坐标构造，接在现有最细八度之后：

- 频率 `K_e = shear_k0·3^(shear_octaves + e)`。几何系数由
  `shear_cascade_geometry(shear_k0·3^shear_octaves, E, shear_ar_small, shear_ar_small, shear_tilt_k, disk_spin)` 给出，
  即长宽比统一取 `shear_ar_small`，拖尾倾角规律与主云相同。延伸八度的形状不再随尺度变化，这是一个简化（§6）。
- 噪声坐标（|N₀₀|_e、P_e、s_e 为几何函数给出的第一坐标缩放、方位周期与剪切系数）：

  ```
  u0  = K_e·(ln r − ln 20)
  ν_e = vnoise(|N₀₀|_e·u0 + ox + 1000,  φ'/2π·P_e + spin·s_e·u0,  K_e·z/r + oz + 23 + 5e;  周期 P_e)
  ```

  φ' 为扣除刚体环带转动后的带内方位角；ox、oz 为刚体环带的种子偏移，与主云共用；
  固定偏移 1000、23 + 5e 使温度起伏与主云、各八度之间去相关。ln 20 原点的作用见 §3.5。
  竖直坐标与剪切级联相同，取 `K_e·z/r`，结构在竖直与径向方向尺度相当。
- 刚体环带混合：两带 × 两种子相位，与大气小尺度起伏 `_atm_fine_I` 相同，按 `Σ_k ω_k·n_k / √Σω_k²` 保方差混合
  （ω_k 为带与相位的混合权重）。结构随气体转动、按带重新播种，视频中不卷绕。四个图案共用同一组钳制权重，
  混合后的方差仍为 V。

### 3.3 频率钳制与透镜

**像素足迹**：

```
F = max(λ, 10⁻³)·θ
```

- λ 为光线从相机出发已走过的路径长度（r_s）。采样点取积分段中点，λ 取到中点的长度，与光行时间所用的量相同；
  步长控制（§3.4）在积分段之前计算，λ 取段起点的长度。
- θ 为输出像素在像平面上的高度。相机像平面距相机 1，按小角度近似即像素角。渲染器的 `pixel_height_field`
  是内部 `ss·W × ss·H` 网格的像素高度，所以 θ = ss·`pixel_height_field`，ss 为每轴超采样倍率（每像素光线数为 ss²）。
  按输出像素计算，单帧（超采样）与视频的细节程度相同。

**钳制权重**：第 e 个八度的径向格宽为 `c_e = r / (|N₀₀|_e·K_e)`：径向噪声坐标为 `|N₀₀|_e·K_e·ln r`，
一格对应 Δln r = 1 / (|N₀₀|_e·K_e)，换算成 r_s 乘 r。当前参数下 |N₀₀|_e = 0.99991。

```
w_e = L · sstep((c_e / F − K) / K)
sstep(s) = 3s² − 2s³，s 先截断到 [0, 1]
```

格宽小于 K 个足迹时完全淡出，大于 2K 个足迹时完全可见；K = `temp_turb_clamp_px`，默认 3。
淡出的八度被其统计均值 0 代替 [1]。有限足迹内的局部平均不严格为 0，所以这是基于零均值噪声的滤波近似。
气体场本身与相机无关，只是采样时按分辨率滤波。

**透镜权重 L**：足迹 λθ 只对近似直线的光线成立。光线经过强透镜后，一个像素对应的气体面积远大于 λθ，
细八度会产生锯齿（推断；原型在透镜像附近出现过亮斑，随后加了 r < 5 的关闭条件）。
真实足迹需要完整的光线映射，本方案用累计偏折角做工程近似：

```
δ = acos(clamp(d̂ · d̂₀, −1, 1))
L = 1 − sstep((δ − δ₀/2) / (δ₀/2))
```

d̂₀ 为光线离开相机时的方向，d̂ 为当前积分段的方向（采样时取段中点方向，步长控制时取段起点方向），均为单位向量；
δ₀ = `temp_turb_lens_deg`，默认 10°。δ < 5° 时 L = 1，δ > 10° 时 L = 0，中间平滑过渡，权重随视角连续变化。
阈值的量级可以用弱场总偏折角估计：δ_total ≈ 2/b rad（b 为冲击参数，r_s 单位）[3]，总偏折 5° 对应 b ≈ 23。
这只用于判断量级，δ 是积分途中的累计偏折角，与总偏折角和最近接半径都不相同；δ₀ 是经验参数，由多视角画面验证。
直视盘面的光线偏折很小、细节保留。最终视频的帧间连续性由运动检查片段确认（§7）。

### 3.4 步长控制

细小的温度结构必须被采到，否则沿视线欠采样会形成规则条纹（A 原型的第一版在地平线一带出现过）。
光线位于大气包络内（含核心）且 L > 0 时，步长额外满足：

```
h ≤ s_c · ½ · max(c_{E−1}, K·F)
```

- c_{E−1} 为最细延伸八度的径向格宽（§3.3）；`max(c_{E−1}, K·F)` 是该处可见的最细格宽。
- s_c 为现有的盘内步长系数：优化级别 0、1 为 1，级别 2 为 2，级别 3 为 3。所以每个可见格宽的采样点数
  在级别 0、1 至少为 2，级别 2 至少为 1，级别 3 约为 0.67。级别 2 的视频观感由原型验证（§2.5），级别 3 只用于预览。
- F 随路径长度增长，总步数随距离对数增长。L = 0 时不施加此约束；现有的核心、大气包络、近视界与光子环步长约束始终生效。
- 参数关闭时，此约束在编译期移除。

### 3.5 数值精度

单精度下，噪声坐标达到 10⁴ 量级时，格内插值出现台阶，画面上形成规则条纹（A 原型实测到主周期 384 像素的竖条）。
本方案的处理：

- 径向坐标以固定的 ln 20 为原点。原点是世界常数，与相机无关。
  E = 2 时最细八度 K = 1620，r ∈ [3, 30] 对应 `K·(ln r − ln 20)` ∈ [−3075, 657]，量级 10³。
- 方位坐标 `φ'/2π·P_e` 的量级约为 P_e。E = 2 时最细八度 P = 4074，单精度舍入约 2×10⁻⁴ 格。
  E = 3 时 P 约 1.2×10⁴，接近 A 原型出现条纹的量级，所以参数校验限制 E ≤ 2。

### 3.7 间歇性与坐标扭曲（v1.5）

**间歇性**（解决 P2）：温度起伏的局部强度随主云密度变化。

```
σ_l = σ_T · m(ĉ)
m(ĉ) = 1                       （γ = 0）
m(ĉ) = clip(ĉ, 0, 3)^γ / M,    M = √⟨clip(ĉ, 0, 3)^{2γ}⟩      （γ > 0）
f_T  = exp(σ_l·n_T − 2σ_l²·V)
```

- ĉ = c/⟨c⟩ 为采样点的归一化主云密度（`density_I` 中已有的 `cn`）；γ = `temp_turb_intermittency`，默认 1.5，0 = 处处同强（v1.4 行为）。
- M 在 ⟨c⟩ 的标定样本上计算（4096 个 z = 0 的随机点，与 ⟨c⟩ 同一组样本），使 ⟨m²⟩ = 1。
  σ_T 的含义变为"全盘均方根强度"：E[σ_l²] = σ_T²。全部 w_e = 1 且 m(ĉ) 与 n_T 近似不相关时，
  全盘平均的 ln T 方差约为 σ_T²；实际值受二者的空间相关性影响，由单测测量（§7 第 13 项）。
- 截断上限 3 防止极少数高密度点的起伏过强。γ = 1.5、σ_T = 0.1 时局部强度最大约 0.28。
- 平均通量守恒：n_T 与 ĉ 使用同一套刚体环带种子、不同的噪声坐标与固定偏移，设计上降低了相关性，但不严格独立。
  所以给定 ĉ 时 ⟨f_T⁴⟩ = 1 仍是基于近似高斯、近似独立、条件方差约为 V 的统计近似；单测按 ĉ 分箱检查
  ⟨f_T⁴⟩ 与 ⟨m²·n_T²⟩ 的偏差（§7 第 13 项）。
- 物理含义：湍流耗散发热集中在密度高、剪切强的团块里，稀薄处起伏弱（工程判断，用主云密度近似湍流强度）。
- 间歇性只改变强度，不改变 n_T 本身，所以 κ 标定（`lens_w = 0`，n_T = V = 0）不受影响。

**坐标扭曲**（解决 P3）：每个延伸八度的前两个噪声坐标在求值前按低频梯度噪声偏移。

```
(x, y, z) 为 §3.2 中第 e 个八度 vnoise 的三个输入坐标，P = P_e，P_w = max(1, round(P/2))
d_x = gnoise(½x + 7.1, y·P_w/P, ½z + 1.7;  周期 P_w)
d_y = gnoise(½x + 13.7, y·P_w/P, ½z + 9.3;  周期 P_w)
ν_e = vnoise(x + A·d_x / s_g,  y + A·d_y / s_g,  z;  周期 P)
```

- A = `temp_turb_warp`（格），默认 0.35，0 = 不扭曲；s_g = 0.19 为 `gnoise` 的实测标准差（`noise_ti.gnoise` 文档），
  使偏移量的标准差约为 A 格。
- 扭曲噪声的频率约为该八度的一半。实数运算下 φ 增加 2π 使 y 增加 P，乘 P_w/P 后扭曲噪声的方位坐标增加 P_w，
  而 `gnoise` 的方位周期也是正整数 P_w，所以扭曲在方位方向有理论周期。P 为奇数时 P_w/P 与 ½ 的差异只改变扭曲噪声的频率，
  不改变周期条件。实际 f32 路径的误差由单测检查，并覆盖 P = 1、2、3 等最小周期（§7 第 14 项）。
- 偏移量只与气体坐标有关，与相机无关；扭曲后的图案仍随刚体环带转动。
- 扭曲会局部压缩特征。A = 0.35 时压缩比约在 1.5 倍以内（推断），频率钳制阈值 K = 3 留有余量；
  A 越大颗粒感越强（§2.6），参数校验限制 A < 1。
- N 的标定使用含扭曲的图案，沿用 §3.1 的 256 × 512、竖直坐标跨越多个格的网格，所以在该标定分布上单图案的方差约为 1；
  四个图案混合后的方差由 §7 第 15 项单独检查。
- 优化级别 0 用 `gnoise`，级别 ≥ 1 用 `gnoise_fast`，二者逐位一致（`DiskV2Taichi._gn`）。

**耗时**：扭曲为每个八度增加两次梯度噪声求值，原型中视频档贴盘帧约增加 40%（§2.6）。

温度属于"② 场景·辐射"层（`imaging_model.md` §2.3），字段放在 `DiskV2VolumeParams`。只有强度开放 CLI，
放在 CLI 的"② 场景·辐射"参数组。

| 字段 | CLI | 默认 | 取值 | 含义 |
|------|-----|------|------|------|
| `temp_turb_sigma` | `--v2_temp_turb` | 0 | [0, 0.5] | 温度起伏强度 σ_T（全部 w_e = 1 时 ln T 标准差的全盘均方根，§3.7）；0 = 关闭 |
| `temp_turb_octaves` | — | 2 | 1 或 2 | 延伸八度数 E（上限见 §3.5）；关闭只用 `temp_turb_sigma = 0` 表示，E = 0 报错 |

| `temp_turb_gain` | `--v2_temp_turb_gain` | 0.69 | (0, 1] | 逐八度幅度比（从最粗的八度起算）；含粗尺度八度时取 1 |

| `temp_turb_intermittency` | — | 1.5 | [0, 3] | 间歇性指数 γ（§3.7）；0 = 处处同强 |
| `temp_turb_warp` | — | 0.35 | [0, 1) | 坐标扭曲幅度 A（格，§3.7）；0 = 不扭曲 |

`temp_turb_gain` 的默认值 0.69 ≈ 3^(−1/3)，借用 Kolmogorov 湍流中速度起伏随尺度的标度 δv ∝ ℓ^(1/3) [4]
（尺度缩小到 1/3 时幅度乘 3^(−1/3)）。温度作为被湍流输运的标量，在惯性区有相同的标度 [5]；
把它用于本模型的值噪声八度是工程近似。

close_low 取 `--v2_temp_turb 0.1`，lensing_bend 取 0.05；interstellar_skim 自 v1.6 起取分形配置
（σ_T 0.134、S = 3、gain 1、K = 1，§9）；其他场景不开启。间歇性与坐标扭曲两个字段不开放 CLI，取默认值。

## 6. 风险、假设与已知限制

- **长宽比简化**：延伸八度统一取 `shear_ar_small`。物理上更小的尺度存活更短，应更接近各向同性；
  A′ 原型的各向同性团块看起来像噪点贴图，所以保留一定的方位拉长（工程判断）。
- **散射光不含温度起伏**：大气散射的入射光取下方盘面的平均源函数，起伏只影响热发射。
- **足迹近似**：足迹按 λθ 估计，忽略离轴像素的像素角缩小与弱透镜的放大率；强透镜由偏折角淡出兜底。
  阈值 δ₀ 是经验值，需在多视角中确认透镜像附近没有锯齿与亮斑。
- **耗时**：close_low 视频档 v1.4 约 1.7 倍、v1.5 约 2.4 倍（§8）；贴盘俯视等近距离视角的步长约束更多，视频档耗时暂无数据。
- **视觉强度随视角变化**：同样 10% 的起伏，竖直往下看时视线穿过的气体更短、平均掉的更少，纹理比掠射时更强
  （原型贴盘俯视视角差 > 20 的像素占 21%）。这是当前模型假设下的预期结果，强度由场景单独设置，并由多视角实测确认。
- **间歇性的物理依据**：用主云密度代替湍流耗散率，是工程近似；γ 与截断上限 3 由画面选定。
- **扭曲与频率钳制**：扭曲压缩特征的程度未逐点计入钳制权重，只靠阈值余量兜底（§3.7）。
- **长时间视频**：结构随刚体环带重新播种，周期与主云相同；原型只做了 3 秒运动检查，长片段在 T5 检查。

## 9. 分形温度湍流：向粗尺度延伸（v1.6）

### 9.1 问题

interstellar_skim 中，相机贴盘飞行一段后，近处的温度细节逐渐变成柔和的烟雾，中远景几乎看不到起伏。
原因是温度起伏只有主云最细八度之后的 2 个八度（K ≈ 540、1620）：离相机稍远，它们的格宽就小于 K 个像素足迹，
被频率钳制完全淡出（§3.3），画面上只剩主云的密度结构。用户要求"大 pattern 由小 pattern 组成"：
大片冷暖斑块内部逐级细分，远处也有纹理。

### 9.2 模型

温度起伏 n_T 的八度列表在原有 E 个延伸八度之前，再加主云剪切级联最细的 S 个八度的尺度：

```
八度顺序（频率从低到高）：主云第 N−S … N−1 级（K = k0·3^k）  +  延伸第 0 … E−1 级（K = k0·3^(N+e)）
幅度：a_e = gain^e（e 从最粗的八度起算）；含粗尺度八度时 gain = 1（等幅）
```

- 粗尺度八度的长宽比、倾角、方位周期与主云对应八度相同（`temp_turb_geometry(..., n_coarse=S, shear_ar_big=…)`），
  噪声坐标偏移按八度序号递增（§3.2），与主云密度不相关：温度斑块与密度团块尺度相同、位置独立。
- 其余部分不变：频率钳制、透镜淡出、方差 V、间歇性、坐标扭曲、⟨f_T⁴⟩ = 1 的归一都按 S + E 个八度计算。
- S = 0 时八度列表与改动前完全相同，渲染结果逐位一致；只有 S > 0 时才增加八度数（耗时随之增加）。
- 粗尺度八度的频率远低于延伸八度，单精度坐标精度不受影响，所以延伸八度的上限 E ≤ 2（§3.5）不变，
  S 的上限为主云八度数 N。

### 9.3 原型实测（远端 4090，1080p，6 个视角）

| 编号 | 配置 | 结论 |
|------|------|------|
| ① | 现状：E = 2，σ_T 0.10，gain 0.69，K = 3 | 贴盘近处有细节，中远景无起伏 |
| ② | 只把 K 降到 1.5 | 与 ① 几乎相同 |
| ③ | S = 2（K 60–1620），每八度 0.07 | 近处细节保留，中景多一层大一号云纹 |
| ④ | S = 3（K 20–1620），每八度 0.06 | 层次最多（用户选定）；skim 52 s 近处有一块偏亮的大云团 |
| ⑤ ⑥ | S = 4（K 6.7–1620），每八度 0.07 / 0.05 | 最粗八度格宽约 3 r_s，贴盘近处整片发暗，否决 |
| — | 按 Kolmogorov 幅度逐级减弱（gain 0.69 / 0.80） | S = 4 共 6 个八度时，最细一级幅度只有最粗一级的 0.69⁵ ≈ 16%（gain 0.80 时 0.80⁵ ≈ 33%），近处变暗、细节消失，否决 |

- 等幅时 σ_T = 每八度幅度 × √(S + E)：④ 为 0.06 × √5 ≈ 0.134。
- ④ 的阈值 K = 1 与 1.5 对比：静帧肉眼几乎相同；540p / 30 fps 运动片段的时间二阶差分（闪烁）
  均值 7.15 / 7.08（/255）、最强 1% 像素 55.3 / 55.0，没有增加闪烁，定 K = 1。
- 加粗尺度八度后，开场远景（t = 0）的外盘边缘碎成亮块，用户接受。
- 耗时：360p / 15 fps 全片 35 min（① 为 19 min），约 1.85 倍。

--v2_temp_turb_clamp_px 1`。同一轮还定了色调：白平衡 10000 K、胶片响应 1、曝光补偿 +3 档（网格对比
白平衡 4500–12000 K × 胶片响应 0 / 0.5 / 1 × 曝光 +2 / +2.5 / +3，贴盘 44 s 中位亮度 0.20 → 0.32，
盘面由灰白变为橙金色）。
