# V2 运镜：关键帧相机路径、节奏与构图

> **状态**：v1.0（2026-10-04），C1–C6 已实施；C7（1080p / 60 fps 正片）待用户指令。
>
> **关联文档**：成像链与相机层见 [`../imaging_model.md`](../imaging_model.md) §3、§5；吸积盘模型见
> [`../design_ad_v2.md`](../design_ad_v2.md)；盘内云雾见 [`v2_unified_gas_plan.md`](v2_unified_gas_plan.md)。
>
> **术语**：
> - **关键帧**：路径上的一个相机状态（位置、黑洞在画面中的位置、视野、滚转）。关键帧不带时刻，只决定相机
>   经过哪里；经过的时刻由节奏曲线决定（§5.4）。
> - **柱坐标**：(r, φ, z)；φ 为世界方位角（与 `--pov` 的 `atan2(y, x)` 一致），z 为离盘面高度（负值为盘下方）。
> - **画面坐标 (u, v)**：u 从左到右、v 从上到下，均在 [0, 1]；三分线为 1/3、2/3。
> - **路径参数 p**：关键帧序号的连续化，p ∈ [0, K − 1]，第 i 个关键帧位于 p = i。
> - **感知进度 S**：沿路径累计的画面变化量（§5.4）；**感知速度** dS/dt 为它随视频时间的增长率。
> - **顺行 / 逆行**：相机方位角变化方向与盘旋转方向相同 / 相反。

---

## 1. 背景

统一气体模型下，相机进入大气层（r = 22 处 z ≲ 0.5）可以看到云雾，远处可以看到盘面纹理与光子环。
原有视频只支持环绕：同距离、同仰角、匀速转方位角、始终看向原点。它无法在一段视频里同时表现远景与云雾，
黑洞也始终在画面正中。目标是一段类似《星际穿越》中飞船接近 Gargantua、掠过盘面的长镜头。

## 2. 原有限制

| 限制 | 位置 | 影响 |
|------|------|------|
| 相机光轴固定为指向原点 | `src/v2/camera.py:build_camera_v1_compatible` | 黑洞始终居中，无法构图 |
| 轨迹只有匀速方位角，距离、仰角、视野、滚转恒定 | `src/cli.py:_render_video_v2` | 不能下降、推近、变焦、压坡度 |
| 曝光首帧锁定 | `DiskV2Renderer.finish` | 远景 → 云中 → 盘底，画面亮度跨约 7 档，锁定曝光无法兼顾 |
| 云的流动取决于相机与气体的相对速度 | 物理事实 | 相机与气体同向等速飞行时，云相对相机静止 |

## 3. 决策（2026-10-04 已确认）

1. **静止观者**：每一帧按位于该处的静止观者成像，运镜只改变相机位置与朝向，不计相机速度带来的光行差与整体频移。
   因此运镜是一串视点的连续变化，相机速度没有物理上限；路径报告给出全程最大局部速度供参考（§5.6）。
2. **相机运动连续**：用户原话"它不会瞬间转向、改变速度，它的配置的一阶导数至少要是连续的，如果二阶导数也是
   连续的是最好"。实现为空间路径与节奏曲线都二阶导数连续（§5.2、§5.4），相机位置、速度、加速度对时间连续。
3. **节奏**：全程不停顿，速度变化少而缓。中段感知速度恒定，开头缓慢加速、结尾缓慢减速各一次。
4. **曝光**：测光 + 平滑（§5.5）。
5. **时长**：87.5 s；俯冲穿越（云缘 → 盘底）约 20 s；首尾淡入 2 s、淡出 3 s。
6. **范围**：只做运镜；运动模糊、手持抖动、胶片颗粒另立项。

## 4. 运镜设计

### 4.1 原则

1. **一镜到底**：整段为一个连续长镜头，没有剪辑点。叙事弧为远景 → 掠云 → 穿过盘面 → 盘底 → 绕盘边回升 → 远景，
   首尾呼应。
2. **进出云层靠高度渐变**：大气密度随高度连续变化，相机高度连续变化时，雾自然由淡到浓、再由浓到淡。
   穿过盘面时约 2–3 s 满屏暗金色雾，用户确认保留。
3. **黑洞在构图位置上**：黑洞是全程唯一主体，关键帧给出它在画面中的位置 (u, v)，相机光轴由此反解（§5.3）。
   史瓦西黑洞的阴影中心严格位于原点方向（球对称），所以黑洞的画面位置就是原点方向的针孔投影。
4. **感知速度恒定**：离黑洞或盘面越近，同样的位移在画面中扫过的角度越大，相机的实际移动相应放慢（§5.4）。
5. **相对运动**：全程逆行，盘面纹理与云层始终相对相机流动。

## 5. 实现

### 5.1 路径文件（JSON）

```json
{
  "duration": 87.5,
  "path_smoothing": 0.5,
  "progress": {"near_weight": 0.03, "near_height_floor": 0.3, "smoothing": 0.3},
  "rhythm": {"ramp_in": 6.0, "ramp_out": 8.0, "speed_start": 0.55, "speed_end": 0.55},
  "exposure": {"metering_step": 0.5, "metering_size": [128, 72], "smoothing": 1.5,
               "gain": 0.6, "ev_range": [-0.9, 1.1]},
  "fade": {"fade_in": 2.0, "fade_out": 3.0},
  "keyframes": [
    {"r": 72, "phi_deg": -179, "z": 10.0, "fov": 32, "roll": 12.5,
     "subject_uv": [0.60, 0.45], "label": "S1"},
    {"r": 54, "phi_deg": -72, "z": 8.0, "fov": 34, "roll": 12.5,
     "subject_uv": [0.40, 0.45], "label": "S8"}
  ]
}
```

| 字段 | 含义 | 取值 |
|------|------|------|
| `duration` | 视频时长 T（秒） | ≥ 1/80（节奏曲线至少 3 个时间步），必填 |
| `path_smoothing` | 空间路径高斯平滑标准差 σ_p（关键帧间隔） | ≥ 0；0 = 只做保形插值 |
| `progress.near_weight` | 近景视差权重 c_near：贴近盘面时同样位移显得更快的程度 | ≥ 0 |
| `progress.near_height_floor` | 近景视差项的高度下限 z_min（r_s），防止 z → 0 时发散 | > 0 |
| `progress.smoothing` | 感知进度被积函数的高斯平滑标准差（关键帧间隔） | ≥ 0 |
| `rhythm.ramp_in` / `ramp_out` | 起步 / 收尾缓变时长（秒） | ≥ 0，两者之和 ≤ T |
| `rhythm.speed_start` / `speed_end` | 首 / 末帧感知速度与巡航感知速度之比 | (0, 1] |
| `exposure.metering_step` | 测光间隔（秒） | > 0 |
| `exposure.metering_size` | 测光渲染分辨率 [宽, 高]（像素） | 正整数 |
| `exposure.smoothing` | 测光档数的高斯平滑标准差（秒） | ≥ 0 |
| `exposure.gain` | 补偿比例 k：1 = 完全抵消亮度变化，0 = 不补偿 | ≥ 0 |
| `exposure.ev_range` | 补偿量夹取范围 [下限, 上限]（档），叠加在 `--v2_exposure_ev` 之上 | 下限 ≤ 上限 |
| `fade.fade_in` / `fade_out` | 淡入 / 淡出时长（秒） | ≥ 0，两者之和 ≤ T |
| `keyframes[].r` / `phi_deg` / `z` | 相机柱坐标（r_s、度、r_s）；φ 跨关键帧连续取值，不折回 ±180° | r > 0，必填 |
| `keyframes[].fov` / `roll` | 竖直视野角、相机滚转角（度）；滚转正值使画面左低右高 | fov ∈ (0, 180)，必填 |
| `keyframes[].subject_uv` | 黑洞的目标画面位置 (u, v) | [0, 1]，必填 |
| `keyframes[].label` | 镜头标签，只用于报告与联系表 | 可省略 |

- 关键帧至少 2 个；除 `duration` 与 `keyframes` 外的块与字段都可省略，省略时取上面示例中的值（即示例路径的定稿值）。
- 加载与校验：`src/v2/camera_path.py:load_camera_path`、`src/v2/exposure_curve.py:load_metering_settings` /
  `load_fade_settings`，入口为 `src/v2/path_video.py:load_camera_plan`。

### 5.2 空间路径 C(p)：保形插值 + 沿路径高斯平滑

1. 对 7 个配置量 `q = (ln r, φ, z, fov, roll, u, v)`，以关键帧序号 i 为自变量做 Fritsch–Carlson 单调保形三次插值
   （PCHIP，两端导数取 0），在 p 上以每个关键帧间隔 400 点的网格采样。
2. 每个分量沿 p 做截断高斯平滑：`q̃(p) = Σ q(p′)·G_σ(p − p′)`，σ = `path_smoothing` = 0.5 个关键帧间隔，截断 ±3σ，
   两端按端点值延拓。
3. 平滑后的网格采样用三次样条还原为连续函数（`camera_compose.UniformSpline`，二阶导数连续），供任意 p 求值。

- 保形插值只有一阶导数连续，关键帧处二阶导数跳变，镜头在关键帧处显得生硬；高斯平滑消除了这种跳变，
  三次样条还原后路径二阶导数连续（三阶导数在网格点处可有微小跳变）。
- 平滑的代价是路径不严格经过关键帧（§4.3），关键帧应理解为路径的控制点。
- 在 `(ln r, φ, z)` 中插值使轨迹沿盘弯曲，推近时的视觉速度均匀。

### 5.3 构图求解：由黑洞的画面位置反解相机光轴

给定相机位置 p、目标画面位置 (u, v)、竖直视野角、宽高比与滚转 ρ，求光轴 f，使原点投影到 (u, v)：

```
目标在相机系中的方向：d_cam ∝ (x, y, 1)，x = (u − ½)·W_p，y = (½ − v)·H_p，H_p = 2·tan(fov/2)，W_p = aspect·H_p
迭代：f₀ = ŝ = −p / |p|
      由 f_k、世界上方向 +z、ρ 得画面基 (r_k, u_k)（与 build_camera_v1_compatible 相同的构造）
      d_k = normalize(f_k + x·r_k + y·u_k)；把 f_k 绕 normalize(d_k × ŝ) 旋转 ∠(d_k, ŝ) 得 f_{k+1}
```

- 不动点迭代 30 次（常见构图 3–5 次收敛）后检查投影误差。光轴接近竖直时画面基随光轴方位变化剧烈，迭代可能不收敛；
  误差超过 1e-6 的样本改用阻尼高斯–牛顿迭代（在当前光轴的切平面上求解，任何方向都没有坐标奇点），仍不收敛时报错。
- 构图可能无解：画面水平方向由世界上方向 +z 决定，黑洞方向离竖直只有几度到十几度时，黑洞只能落在过画面中心的
  一条窄带内。随机测试（3000 组）中抽查的 25 个报错样本经穷举确认均无解；示例路径的黑洞方向离竖直至少约 82°，不受影响。
- 单测验证随机构图与接近竖直的构图投影误差 < 1e-6；联系表实测目标与实际位置一致到 0.001。
- `build_camera_v1_compatible` 新增可选参数 `forward`（默认 `−p/|p|`，与原实现逐位一致）；
  `DiskV2Renderer.render_hdr` 新增 `forward`、`roll_deg`，逐帧传入。

### 5.4 节奏：感知进度 + 恒定感知速度

**感知进度**（每一小段路径的画面变化量）：

```
dS = |dx|·(1/ρ + c_near / max(|z|, z_min)) + dθ + ½·|dfov| / fov
```

- `x` 为相机位置，`ρ = |x|` 为到黑洞的距离：离黑洞越近，同样位移在画面中扫过的角度越大；
- `c_near / max(|z|, z_min)` 为贴近盘面时的近景视差项，`c_near = 0.03`，`z_min = 0.3`；
- `dθ` 为相邻两点光轴的夹角（转头），`dfov / fov` 为变焦的相对变化；光轴按固定宽高比 16:9 求解，使节奏与输出分辨率无关。
- dS 沿 p 再做一次高斯平滑（σ = 0.3 个关键帧间隔）。`max(|z|, z_min)` 在 |z| = 0.3 处、`|dfov|` 在变焦方向反转处
  有拐点，不平滑时 p(t) 的加速度会跳变，相机每次经过 |z| = 0.3 都会顿一下；平滑后加加速度的最大值下降约 18 倍，且与帧率无关。

**节奏曲线**（感知速度对视频时间 t）：

```
v(t) = c · w(t)
w(t) = 1 − (1 − v_s)·(1 − ss(t / T_in)) − (1 − v_e)·(1 − ss((T − t) / T_out))
ss(s) = 6s⁵ − 15s⁴ + 10s³（s 截断到 [0, 1]）
c 由 ∫₀ᵀ v dt = S_total 解出；S(t) = ∫₀ᵗ v dt；p(t) 满足 S(p(t)) = S(t)
```

- 全程不停顿；速度只变化两次：开头 6 s 由 0.55c 升到 c，结尾 8 s 由 c 降到 0.55c，中段恒定。
- ss 两端一、二阶导数为 0，v(t) 二阶导数连续；相机位置、速度、加速度对时间连续。
- 数值实现：t 按 1/240 s 网格梯形积分；S(p) 用三次样条表示，p(t) 先线性插值得初值、再做两步牛顿迭代；
  p(t) 同样用三次样条还原为连续函数。若改用分段线性插值，加加速度在网格点处跳变，30 fps 与 60 fps 测得的最大值
  相差约 94%；三次样条下单测验证两者一致（差异 < 0.2%）。

### 5.5 曝光：测光 + 平滑

1. **测光**：正式渲染前，每 0.5 s 渲染一张 128×72 的 HDR（优化级别 3、超采样倍率 1、抖动种子固定），
   取盘区亮度水平 `L(t) = p99.9(盘区像素亮度)`（只计亮度 > 1e-4 的像素，与自动曝光一致）。
2. **自动曝光档数**：`a(t) = −(log₂ L(t) − log₂ L(0))`，即让该时刻盘区 p99.9 回到首帧水平需要补偿的档数（正值为需提亮）。
3. **平滑**：`ā = a ∗ G_σ`，σ = 1.5 s（截断 ±3σ，两端按端点值延拓）。
4. **部分补偿**：`ev(t) = E_c + clip(k·ā(t), −0.9, +1.1)`，E_c 为 `--v2_exposure_ev`（默认 +1.5），k = 0.6。
   k < 1 使亮处仍更亮、暗处仍更暗，保留进云变亮、盘底变暗的明暗变化，又不至于全白或全黑。
5. **逐帧曝光**：首帧（正式分辨率）计算一次自动曝光 `E₀ = 0.9 / p99.9(L₀)`；第 f 帧曝光 `E_f = E₀ · 2^{ev(t_f)}`，
   ev 在测光点之间线性插值。

示例路径实测：穿越前后 a 最高约 +6.8 档，补偿后 ev 在 +1.15 … +2.60 档之间平滑变化。

### 5.6 淡入淡出、路径报告与检查

- **淡入淡出**：在 sRGB 编码值上乘 `α(t) = sstep(min(t / T_fi, 1, (T − t) / T_fo))`，`sstep(s) = 3s² − 2s³`，
  T_fi = 2 s、T_fo = 3 s。它是剪辑操作，不改变曝光。时长为 0 的一侧不淡变。第 f 帧取 t_f = f / fps，末帧
  t_last = (round(T·fps) − 1) / fps；示例路径 87.5 s、60 fps 时 t_last = T − 1/60，淡出系数约 9.3e-5，视觉上为黑场。
- **路径报告**（渲染前打印）：
  - 每个关键帧的标签、经过时刻、柱半径、高度、相机速度（r_s / 视频秒）、方位角速度（注明顺行 / 逆行），
    以及在盘内（r_in < r < r_out）时相对气体的角速度 `dφ/dt − ω_gas`，`ω_gas = disk_spin·(180/π)·√(0.5 / r³)·P_in / T_orbit`（度 / 视频秒，T_orbit 为 `--v2_orbit_seconds`）；
  - 全程最大局部速度：坐标速度按物理时间换算为光速单位后，`v_loc = √((v_r / A)² + v_⊥² / A)`，`A = 1 − 1/ρ`
    （史瓦西度规下当地静止观者测得的速度）；
  - 每次穿越 z = 0 的时刻、柱半径，以及是否在盘内。
  示例路径穿越两次：48.6 s（r = 22，穿过盘内）与 72.4 s（r = 36，盘外，无气体）；最大局部速度约 1.01 c（t = 4.8 s，
  远景推近段）。按决策 1，这只说明该段运镜无法由真实飞船拍到，不影响画面。
- **路径检查**：每 0.1 s 采样一次（含终点），以下情况报错：光轴与 ±z 的夹角小于 1°（画面水平方向无法由世界上方向确定）；
  相机离黑洞小于 3 r_s（最内稳定圆轨道以内的强引力区，盘模型不覆盖）；构图无解（§5.3）。穿越盘面属于有意设计，
  不报错。视频与单帧模式渲染前都执行检查。

### 5.7 CLI 与视频管线

| 参数 | 层 | 含义 |
|------|------|------|
| `--v2_camera_path FILE` | ④ 相机 | 运镜路径文件。视频模式下每帧的相机由路径给出，曝光改为测光 + 平滑，首尾淡入淡出；帧数 = round(T · fps)。`--pov`、`--fov`、`--v2_camera_roll` 不生效；不能与 `--orbit`、`--interactive` 同用 |
| `--v2_camera_path_time T` | ④ 相机 | 单帧模式：渲染路径在视频时刻 T（0 ≤ T ≤ 路径时长）的画面，用于检查构图；曝光为单帧自动曝光 + `--v2_exposure_ev` |

- 参数组合校验（`validate_args`）：路径只支持 `--disk_model v2`；不能与 `--orbit`、`--interactive` 同用；单帧模式必须给
  `--v2_camera_path_time`，视频模式不能给；`--v2_orbit_seconds` 必须是有限正数。`--n_frames` 默认为 round(T · fps)，
  显式传入且不等于该值、或该值为 0 时报错。
- 物理时刻：`t_phys = 2000 + t · P_in / v2_orbit_seconds`，`P_in = 2π / √(0.5 / r_in³)`（内缘开普勒周期，与环绕视频一致）。
- 第 f 帧：视频时刻 `t_f = f / fps`，抖动种子 `f + 1`；GPU 积分与后处理（曝光、镜头、ISP、淡入淡出）流水线并行。
- 首帧画面中没有盘区像素时，E₀ 回退为 1.0（与单帧自动曝光一致）；测光中没有盘区像素的时刻由相邻有效测光点在 log₂ L 上线性插值，
  两端取最近有效值；全部测光点都没有盘区像素时不补偿（ev ≡ E_c）。
- 分段与续传沿用 `src/v2/video_segments.py`：进度文件保存 E₀；续传校验的参数包含路径文件全部内容；
  曝光曲线每次运行重新测光（抖动种子固定，结果可复现，约 2 分钟）。
- 联系表：`scripts/contact_sheet.py`，默认取每个关键帧的经过时刻各一格（360p），画三分线（灰）、黑洞目标位置
  （青色十字）与实际投影位置（品红圆圈）；曝光为单帧自动曝光，所以穿越盘面那一格偏亮。

## 8. 风险与局限

- **路径不严格经过关键帧**：空间平滑的代价，首末关键帧偏离约 2 r_s；调整关键帧时以联系表与路径报告为准。
- **穿越盘面的雾**：约 2–3 s 满屏暗金色，测光补偿夹在上限 +1.1 档；用户已确认保留。
- **测光分辨率**：测光用 128×72、优化级别 3，与正片不同；只用其相对首帧的变化量，偏差基本抵消。
- **速度**：1080p 级别 2 约 6.4 s/帧（估算），5250 帧约 9.3 h，另加测光约 2 min。
- **静止观者近似**：示例路径远景推近段的局部速度约达 1 c，真实飞船无法这样飞行，飞得这么快时画面也应有明显的
  光行差与整体频移；按决策 1 忽略。若要求运镜对应真实飞船，需放慢该段或调小 `--v2_orbit_seconds`
  （每视频秒对应更长的物理时间，相机的物理速度随之降低，盘也转得更快），并以路径报告的最大局部速度验收。
