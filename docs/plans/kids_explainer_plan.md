# 儿童科普片《黑洞是什么》执行方案

> **状态**：v0.3（2026-10-13），方案已确认，未实施。
>
> **关联文档**：制片层架构见 [`../design_film.md`](../design_film.md)；渲染引擎见 [`../design_ad_v2.md`](../design_ad_v2.md)、
> [`../imaging_model.md`](../imaging_model.md)；运镜路径格式见 [`v2_camera_path_plan.md`](v2_camera_path_plan.md) §5.1。
>
> **术语**：
> - **k / d / w**：三个场景旋钮——引力强度 `gravity_scale`、多普勒强度 `doppler_scale`、盘的气体量 `disk_weight`（§3）。
> - **宇宙遥控器**：画面角落的三旋钮叠加层，旋钮值由同一条旋钮轨道驱动（制片层设计 §4.6）。
> - **想象实验**：片中"拧旋钮"的叙事框架。现实中引力不能调，画面上标注"想象一下"。
> - **E₀**：视频锁定的自动曝光系数（现有行为：正片第 0 帧盘区 p99.9 → 0.9）。
> - **gain**：测光补偿比例（`exposure.gain`，0 = 首帧锁定、不随亮度补偿）。
> - **reference_time**：`exposure` 块新字段，指定 E₀ 的测光时刻（§3.3）。
> - **D_i / x_i**：镜头 i 的时长 / 与上一镜头的交叉淡化重叠时长（制片层设计 §4.2）。

---

## 1. 目标

给 8–12 岁儿童讲清楚黑洞是什么，时长约 3–3.5 分钟（按配音实际时长定），横屏 1080p30，中文 TTS 旁白，烧录字幕。

看完应记住四件事：
1. 黑洞把很多东西挤在很小的地方，引力大到**连光都跑不出来**，所以是黑的；
2. 引力把光**掰弯**，所以盘背面的光绕过头顶，黑洞看起来"戴着帽子"；
3. 气体转得飞快，**朝我们转来的一侧更亮、更蓝**（多普勒效应）；
4. 黑洞**不是吸尘器**，离我们很远，不危险；科学家**真的拍到了**它的影子。

## 3. 引擎层改动：三个场景旋钮

### 3.1 物理定义

| 旋钮 | 含义 | 取值 | 作用位置 |
|------|------|------|----------|
| `gravity_scale` k | 黑洞质量缩放：质量 k·M | [0, 1] | 光线加速度、视界半径、引力红移、光子方向变换、静止相机光行差修正、光子环步长保护带、近视界步长 |
| `doppler_scale` d | 盘轨道速度缩放，**只用于频移** | [0, 1] | 频移公式中 β → d·β |
| `disk_weight` w | 盘的气体量 | [0, 1] | 合成后的总发射与总消光（含大气散射项）整体乘 w；w = 0 时跳过盘采样（光线追踪、视界判定与天空透射不变） |

公式（r_s = 1，原式见 `taichi_render.py` 与 `relativity.py`）：

```
a        = −1.5 · k · L² · x / r⁵                          light ray (mass k·M)
r_cap    = max(k, 10⁻³) · r_s                               horizon capture
g_grav   = √(1 − k·r_s/r) / √(1 − k·r_s/r_obs)              gravitational redshift
dir_loc ∝ dir_rad + √(1 − k·r_s/r) · dir_tan                local photon direction
β'       = d · β(R),  γ' = 1/√(1 − β'²)                     orbital speed for Doppler only
g        = g_grav / (γ' (1 − β' cosθ))
j_total, α → w·j_total, w·α                                 emission & extinction (incl. scatter)
```

- **为什么 k 是质量缩放**：Schwarzschild 等效势方程 `a = −1.5 r_s L² x / r⁵` 中 r_s ∝ M，所以 k 不是凭空的系数。
  **就光线测地线、视界与引力红移而言**，中间值对应质量 k·M 的真实时空：视界 k·r_s、光子球 1.5k·r_s、
  **阴影半径 (3√3/2)·k ≈ 2.6k r_s**，全部按 k 线性缩放。盘气体的轨道速度不随 k 缩放（见 Simplifications）；
  影片中 k 变化的镜头（s04）都把 d 设为 0，不会露出这一不一致。
- **k → 0**：没有黑洞，光走直线，盘内缘以内透出星光；k 增大，黑洞从一个点长出来，阴影长到 2.6 r_s，盘背面翻上头顶。
- **吞光半径下限 10⁻³**：防止贴近原点的光线出现 `inf × 0 = NaN`；被下限吞掉的光线不到一个像素。
- **近视界步长与光子环保护带随 k 缩放**：`h ≤ 0.02·k' + 0.06·max(r − k', 0)`（k' = max(k, 10⁻³)），保护带
  `b ∈ [2.4k, 4.0k]`，保证小 k 时光子环仍被细步长采样。
- **w 的实现约定**：w 乘在**合成后**的 `j_total`（核心热发射 + 大气热发射 + 大气散射）与 `alpha_coeff` 上，
  不缩放温度湍流倍率 `tf_c`；`> 1e-9` 门控在缩放前、按原始密度值判断（w = 1 时行为不变）。
  w = 0 时跳过整个盘采样（`density_I` 不调用），透射率、视界命中与天空贡献不受影响。
- **k = d = w = 1 时的验收**：新因子均以乘法追加，保持原有运算顺序（IEEE 754 下 `x·1.0` 精确、
  `max(1.0, 10⁻³) = 1.0`），但**逐位一致以测试为准**：实现时逐处保持旧运算顺序，用
  `git archive HEAD src` 导出旧版做 HDR 与天空双路逐位对比（§6），不以本条论证代替测试。

**Simplifications**：盘的结构（内外半径、温度剖面、平流转速、光行时间）不随 k、d 变；**盘气体的轨道 β
及其 ISCO 钳制按基准质量（k = 1）计算，不随 k 缩放**——所以"k 旋钮 + d = 1"的组合在物理上不自洽，
影片中不出现；d 不影响盘的旋转动画；k 变化时相机位置不变（距离以 r_s 为单位）。

### 3.2 旋钮轨道（路径文件 `scene_anim` 块）

```json
"scene_anim": {
  "gravity_scale": [[0, 1.0], [4, 1.0], [9, 0.0], [12, 0.0], [17, 1.0]],
  "doppler_scale": [[0, 0.0]],
  "disk_weight":   [[0, 1.0]]
}
```

- 每条轨道为 `[时刻（秒）, 值]` 列表，时刻严格递增；相邻关键帧之间用五次缓动 ss（与摇镜相同，两端速度、加速度为 0），
  首帧之前、末帧之后保持端值。
- 省略的轨道取 CLI 参数值（默认 1）；同一旋钮同时有轨道和 CLI 参数时以轨道为准，并打印提示。
- 新模块 `src/v2/scene_anim.py`：`load_scene_anim(spec)`、`SceneAnim.values_at(t)`，纯 NumPy，
  不得 import Taichi——遥控器叠加层要在制片层进程内逐帧求值它。

### 3.3 曝光参考时刻

旋钮镜头需要锁定曝光（`exposure.gain = 0`），否则自动测光会把"盘亮起来"补偿掉。但首帧可能没有盘
（w = 0），无法测光。路径文件 `exposure` 块新增 `reference_time`（秒，默认 0）：

- **默认 0**：E₀ 仍取自正片第 0 帧（现状，逐位一致）。
- **非零**：用**正片渲染器**（同分辨率、质量与超采样，种子与第 0 帧相同）在 `reference_time` 时刻渲一帧
  参考 HDR，对它做 `auto_exposure` 得到 E₀。不使用低分辨率测光渲染器（种子与优化级别都不同，
  p99.9 不可比）。E₀ 继续交给现有分段进度保存，`--resume` 行为不变。

`reference_time` 只决定 E₀；测光曲线 ev(t) 仍以 t = 0 的亮度为基准（gain = 0 时无影响）。
建议把旋钮镜头的 `reference_time` 设在"目标外观"时刻（如 s03 取 w = 1 处、s04 取 k = 1 处），
S5 小样确认极端帧（k → 0）不过曝 / 欠曝。

### 3.4 CLI 与渲染器

- `DiskV2Renderer.set_scene_knobs(gravity_scale, doppler_scale, disk_weight)`：写入三个 Taichi 运行时标量，
  校验取值范围；不重新编译（旋钮必须是运行时读数，不得进 `ti.static`，否则每个取值都触发重编译）。
  `render_path_hdr` 每帧按 `scene_anim` 求值后调用它；**测光渲染器同样应用**（否则沿路径测光测到的是
  错误亮度）。
- 新参数组"场景·想象实验"：`--v2_gravity_scale`、`--v2_doppler_scale`、`--v2_disk_weight`（单帧与不带轨道
  的视频）。这是**教学控制组**而非新的成像物理层：三个旋钮分别控制时空弯曲（结构）、频移（辐射）与
  气体量（结构 + 发射吸收），收尾时在 `imaging_model.md` 的参数分层中按此注明。
- `--v2_color_cap`（K，0 = 不封顶；默认跟随白平衡）开放渲染器已有的 `color_temp_cap_K`，供多普勒演示
  镜头取消封顶；进"场景·辐射"组（与同族的 `--v2_color_floor` 一致，二者都作用于色度温度）。
- 联系表脚本 `scripts/contact_sheet.py` 同样按轨道设置旋钮。

## 4. 内容设计

### 4.1 调研结论（2026-10-13）

对照 NASA Science（黑洞总览、类型、结构三页）、NASA Goddard 2019 与 2024 可视化（含官方旁白字幕）、Chandra 黑洞入门、
ESO/EHT 新闻稿（eso1907、eso2212）、中国科普博览（左文文《给黑洞拍照》、王松 2024）、物理教育研究
（Pinochet 2019、Riggs 2019、Pössel 2018），结论：

- **得到印证**：光线弯曲（"帽子"）与多普勒段落和 NASA "黑洞结构"页几乎逐拍一致；警笛类比是 NASA 自己的；
  逃逸速度框架是 Chandra/NASA 定义视界的方式。
- **独特之处**：调研范围内没有人连续拧动物理上自洽的参数，都是固定画面或前后对比。
- **需要补的**：主动破除"吸尘器"误解；"银河系中心也有一个"；结尾回顾；约 10 秒无旁白的壮观画面。
- **概念密度**：原稿约 2:55 内 9 个段落，偏密；8–12 岁宜 3–4 个核心概念，每个 20–30 秒，5 秒内抛出问题。
- **不加**：掉进去会怎样（意大利面化）、时间变慢——超时，留作续集或短视频。

## 6. 测试要点

**引擎层（S1）**
- k = d = w = 1 时与改动前**逐位一致**：360p、两个视角、HDR 与天空两路、优化级别 0 与 3；旧版用 `git archive HEAD src` 导出。
- `reference_time`：缺省时曝光与改动前逐位一致；非零时 E₀ 取自参考帧（同正片渲染器与种子）；
  越界（> 路径时长）报错；参考帧无盘区像素时回退 E₀ = 1.0（与 `auto_exposure` 现行为一致）。
- NumPy `disk_g_factor`：默认参数与原值逐值相同；k = 0 且 d = 0 时 g = 1；d = 0 时 g = g_grav；
  Taichi 版与 NumPy 版在 (k, d) ∈ {0, 0.5, 1}² 组合下逐值一致。新 CLI 参数进 `test_v2_cli`；
  `--v2_color_cap 0`（不封顶）与颜色下限、白平衡的组合行为进现有颜色截断单测。
- **多普勒方向**：盘逆时针旋转、相机在 −y 方向时，画面左侧气体朝相机运动，g > 1，亮度高于右侧（按几何推导断言，
  对应 AGENTS.md 踩坑第 22 条的历史疑问）。
- k = 0 时光线不弯曲：天空采样方向等于像素初始方向。
- 阴影半径：`geodesic.py` 的临界冲击参数为 (3√3/2)·k；渲染的视界命中区域随 k 单调变大。
- `scene_anim`：读取与校验（时刻严格递增、值域钳制）、五次缓动端点、端值保持、轨道缺省时取 CLI 值、
  同一旋钮轨道与 CLI 参数同设时以轨道为准并打印提示。
- w = 0：盘的 HDR 全为 0、天空透射不受影响；0 < w < 1：`j_total` 与 `alpha_coeff` 按比例、`tf_c` 不变。

**制片层（S2、S6、S7）**：见制片层设计 §6。

## 7. 风险

| 风险 | 应对 |
|------|------|
| 小 k 时光子环采样不足、出现噪点 | 步长与保护带随 k 缩放（§3.1）；S5 小样逐帧检查 k 渐变段 |
| 旋钮镜头锁定曝光在极端帧（k → 0、w = 0）过曝 / 欠曝 | `reference_time` 取目标外观时刻（§3.3）；S5 小样查极端帧直方图 |
| 取消色温封顶后盘整体偏蓝、不好看 | S5 小样对比白平衡；必要时只在 s07 取消封顶 |
| M87* 倾角约 17° 未经一手核实 | S5 前查 EHT 论文（Paper IV–VI）确认倾角与亮弧朝向，再定 s09 相机 |
| 俯视对比镜头与 EHT 照片形状差异大 | 调盘外半径与模糊；仍不像时只并排展示、旁白不强调"一样" |
| TTS 童声不自然 | S4 先试听；不满意可改为自己录音，时间线流程不变 |
| Manim 中文字体、ffmpeg 缺 libass | S0 验证 |
| 脚本反复修改导致返工 | 旁白先行：S4 锁定时长后再做画面 |
