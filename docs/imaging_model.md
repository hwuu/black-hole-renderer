# 黑洞渲染的成像原理

> **版本**：v1.1（2026-10-04：统一气体模型；曝光补偿 +1.5 档、白平衡 4500 K、眩光 0.5）。
>
> **定位**：本文讲清楚"一个像素的颜色是怎么来的"——从黑洞附近发光的物质，到屏幕上的 sRGB 值，
> 每一步模拟的是什么物理过程、用什么公式、哪些地方偏离了物理以及为什么。吸积盘本身的模型细节见
> [`design_ad_v2.md`](design_ad_v2.md)；参数定稿值与调参记录见 [`plans/`](plans/)。
>
> **适用范围**：Disk V2（`--disk_model v2`）。V1 的成像链见 [`design.md`](design.md)。

## 1. 总览：从光到像素

渲染器模拟的是一台真实相机拍摄黑洞的全过程。光依次经过五个环节：

```
+----------------+   +----------------+   +----------------+   +----------------+   +----------------+
| 1. Scene       |   | 2. Camera      |   | 3. Lens        |   | 4. Sensor      |   | 5. ISP         |
| radiance       |-->| pinhole, roll, |-->| PSF: glare +   |-->| exposure       |-->| white balance, |
| geodesics,     |   | orbit,         |   | axial CA,      |   | p99.9 -> 0.9,  |   | ACES tone map, |
| disk RT, sky   |   | supersampling  |   | lateral CA     |   | x 2^EV (lock)  |   | sRGB encode    |
+----------------+   +----------------+   +----------------+   +----------------+   +----------------+
```

| 环节 | 回答的问题 | 输出 | 代码 |
|---|---|---|---|
| 1. 场景光 | 每个方向上进入相机的光有多亮、什么颜色 | 线性 HDR 辐亮度（盘 + 天空两路） | `taichi_render.py`、`taichi_impl.py`、`palette.py` |
| 2. 相机 | 每个像素对应哪个方向（取哪些光线） | 像素网格上的 HDR | `camera.py`、`taichi_render.py` |
| 3. 镜头 | 镜头把每个点的光摊成什么形状 | 被点扩散函数卷积后的 HDR | `postfx.apply_lens_psf`、`apply_lateral_ca` |
| 4. 传感器 | 多少光对应"正常曝光" | 曝光归一化后的 HDR | `taichi_render.finish` |
| 5. ISP（图像信号处理） | 怎样把 HDR 变成好看的显示值 | 8-bit sRGB | `postfx.py` |

**两条贯穿全文的原则**：

1. **每层只做本层的物理**。场景层决定"有什么光"，镜头层只搬运光、不创造光，传感器层只缩放，ISP 层只做
   显示映射。偏离物理的取值（艺术夸张）必须显式参数化、写明物理值，并放在它所属的层。
2. **诊断按层、按阶段量化**。画面问题先逐层打印"每个像素被加了/改了多少"（HDR 域逐级差分），定位到层，
   再看该层的参数——不要在错误的层打补丁（§9 的 bloom 事件就是反例）。

## 2. 场景光：进入相机的光

渲染采用**逆向光线追踪**：从相机出发，沿每个像素方向反向追踪光子的路径，沿途累积这条路径上进入相机的光。

### 2.1 光线传播：弯曲时空中的零测地线

史瓦西黑洞（无自旋）周围，光沿零测地线传播。本项目使用笛卡尔等效势形式（几何单位，`r_s = 1`）：

```
d²x/dλ² = −1.5 · L² · x / r⁵,    L = |x × dx/dλ|（角动量，守恒）
```

- 积分器：RK4，步长随位置连续变化（远处大步、盘内与光子球附近小步）。
- 终止条件：落入事件视界（`r < 1`）；逃逸到 `r_escape = max(r_max, 2·相机距离, 1.6·r_out)`；
  或沿途透射率降到 `1e-3` 以下（后方的光已被完全遮挡）。
- 这一层产生全部引力透镜现象：黑洞阴影、光子环、盘背面被"翻"到黑洞上下方、星空扭曲。

### 2.2 结构场：盘"长什么样"

吸积盘是三维半透明介质（体积密度场），采用统一气体模型：Shakura–Sunyaev 外区的标高与柱密度给出
同一团气体，竖直方向是致密的高斯核心（盘面）加稀薄的指数大气，二者共用一个剪切级联湍流场——大气跟随
下方湍流，稀处出现空隙，并带小尺度起伏随高度逐渐去相关。结构用刚体环平流随时间旋转，任意时长都不产生
差速卷绕。公式与参数见 [`design_ad_v2.md`](design_ad_v2.md) §3.2。

本层参数（"盘长什么样、怎么动"）：内外半径、盘俯仰 / 滚转、旋转方向、盘厚缩放、主云明暗起伏、
大气柱密度比 / 标高 / 小尺度起伏、内缘轨道周期对应的视频秒数——见 §7 表中 ① 层。

### 2.3 辐射转移：盘"发出什么光"

沿光线的每个积分段，按发射-吸收方程累积（发射含热发射与大气对下方盘面光的单次散射）：

```
ΔI = T_trans · (j/α) · (1 − e^(−α·Δs)),    T_trans ← T_trans · e^(−α·Δs)
```

- **温度**：Page–Thorne 相对论薄盘温度 `T(r)`（盘面主体约 3000–5000 K，内缘更热）；核心与大气共用灰大气
  竖直温度规律，从中面到大气顶连续下降。
- **小尺度温度湍流**（可选，默认关）：温度再乘对数正态起伏 `exp(σ_l·n − 2σ_l²·V)`（平均热辐射通量 ⟨T⁴⟩ 守恒），
  n 为主云剪切级联向更小尺度延伸的起伏，比像素小的尺度淡出（频率钳制，方差降为 V）；局部强度 σ_l 随主云浓淡成片变化
  （间歇性），噪声坐标经过扭曲、不呈行列排布。只改温度、不改密度与遮挡，
  使贴盘面视角的近处云层出现细节；远景几乎不变。见 [`plans/v2_temperature_turbulence_plan.md`](plans/v2_temperature_turbulence_plan.md)。
- **散射**：大气的散射反照率 `ω = 1/(1 + q·ρ/ρ_mid)` 由密度决定（稀处以电子散射为主），散射的入射光取下方
  盘面的发射 `(1 − e^{−τ_c})·S_disk`，所以大气呈当地盘面的金色。
- **频移**：光子从物质参考系到相机的频移因子 `g = ν_obs/ν_em = g_grav / (γ(1 − β·cosθ))`
  （引力红移 + 多普勒）。黑体经频移后仍是温度 `g·T` 的黑体，所以亮度和颜色都由"表观温度"决定。
- **亮度与颜色分开**：
  - 亮度 `Y(s · g^{p·k} · T) / Y(s · T_peak)`：`Y` 为可见光波段黑体亮度；
  - 色度 `χ(clamp(T · g^q, T_floor, T_cap))`：`χ` 为 CIE 黑体色度。
- **显式的艺术参数**（物理值均为 1 或 0，偏离是为了好看，全部放在本层）：

| 符号 | 参数 | 默认 | 物理值 | 作用 |
|---|---|---|---|---|
| `s` | 亮度温度倍率 | 1.25 | 1 | 抬亮外盘（Wien 段亮度对温度极敏感，外盘物理上几乎全黑） |
| `p` | 多普勒亮度指数 | 0.25 | 1 | 减弱左右明暗不对称（物理值下通量比可达数倍） |
| `q` | 多普勒颜色指数 | 0.75 | 1 | 减弱逼近侧偏白、远离侧偏红 |
| `T_cap` | 色温上限 | = 白平衡色温 | 无 | 最亮处止于白色、不越过白点变蓝（随 §6 白平衡自动变化） |
| `T_floor` | 色温下限 | 0（关） | 无 | 冷区固定为暗金，只靠亮度变暗 |

`k` 为亮度温度倍率对多普勒明暗的补偿系数（`s = 1` 时为 1），见 [`design_ad_v2.md`](design_ad_v2.md) §3.3。

**本层输出**：每个像素的盘发射 `ΣΔI`（线性 HDR，单位任意但各像素间可比）。

### 2.4 背景：星空

- 天空盒是 sRGB 编码的图像，先解码为线性光、双线性采样。
- 光线逃逸方向决定采到天空的哪一点；穿过盘的光线乘以剩余透射率（被盘遮挡的星光变暗）。
- 天空以独立系数 `sky_gain` 叠加在盘的曝光之后：`x = 曝光·盘 + sky_gain·天空`。星空亮度与盘曝光解耦，
  调星空不会改变盘的曝光。

## 3. 相机：取哪些光线

- **针孔模型**：相机位于 `pov`，默认看向原点，世界上方向 `+z`；竖直视场 `fov`。像平面位于前方单位距离处、
  高 `2·tan(fov/2)`、宽按宽高比；像素 `(i, j)` 的光线方向为 `forward + x_i·right + y_j·up`（`x_i`、`y_j`
  为像素中心在像平面上的坐标）归一化。
- **相机滚转**：基向量绕光轴旋转 ρ：`right' = cos ρ·right − sin ρ·up`，`up' = sin ρ·right + cos ρ·up`；
  +ρ 时画面左低右高。它在画面系中生效，环绕过程中倾角恒定（区别于盘滚转：盘滚转固定在世界系，
  环绕时画面倾角会漂移）。
- **环绕**：视频中相机方位角线性变化 `azim_f = azim_0 + orbit_degrees · f/(n_frames − 1)`，距离与仰角不变。
- **运镜路径**（`--v2_camera_path`）：相机位置、视野、滚转逐帧由路径给出，光轴由"黑洞在画面中的位置 (u, v)"
  反解，使黑洞落在构图位置（如三分线）。黑洞阴影中心严格位于原点方向（史瓦西度规球对称），所以黑洞的画面位置
  就是原点方向的针孔投影。路径在关键帧之间光滑过渡，中段画面变化速度恒定（离黑洞或盘面越近，相机移动越慢），
  开头与结尾各缓变一次；相机位置、速度、加速度对时间连续。设计见 `plans/v2_camera_path_plan.md`。
- **静止观者**：相机运动只改变位置与朝向，不计相机速度带来的光行差与整体频移。
- **超采样与抖动**：以 `N×N` 倍内部分辨率积分后盒式下采样；每帧首步随机偏移（第 f 帧种子 = f + 1），
  构成蒙特卡洛体积积分，消除采样网格条纹。这一步是"像素对光的积分"，相当于传感器像素有面积。

## 4. 镜头：点扩散函数（PSF）

### 4.1 模型

真实镜头不会把一个点成像为一个点：每个点的光按**点扩散函数（PSF）**摊开。成像 = 场景光与 PSF 的卷积。
PSF 由两部分组成：

- **尖锐核心**：绝大部分能量落在一个像素内；
- **长尾**：约 ε 的能量因镜片散射、灰尘、滤镜扩散到很远——这就是**眩光 / 辉光**。

渲染器的镜头模型（`postfx.apply_lens_psf`）：

```
out_c = (1 − ε) · x_c + ε · (K_c ∗ x_c)
K_c   = Σ_k w_k · G(r_k · s_c),   r_k = H / d_k,   Σ w_k = 1
```

| 符号 | 含义 | 默认 |
|---|---|---|
| `ε` | 眩光强度：每个点散射到长尾的能量比例（`--v2_lens_glare`） | 0.5 |
| `(d_k, w_k)` | 长尾的 4 个高斯分量：半径 = 画面高度 / d_k，权重随尺度递减，近似 ~1/r^n 衰减 | (60, 0.40), (20, 0.30), (7, 0.20), (3, 0.10) |
| `s_c` | 逐通道核宽（轴向色差）：蓝光核略宽，高反差边缘外侧自然出现淡蓝边 | (1, 1, 1.15) |
| `G(r)` | 半径 r 的三次盒式模糊（≈ 高斯），边界**补 0**（散射到画面外的光丢失） | — |

之后是**横向色差**（`apply_lateral_ca`）：不同波长放大率略有差异，R 通道以画面中心为原点放大 `(1 + 0.0025)`、
B 通道缩小 `(1 − 0.0025)`，高反差边缘出现红/蓝各偏一侧的细彩边。它是几何重采样，不加光。

### 4.2 三条性质（也是判断任何镜头效果对不对的标准）

1. **线性、无阈值**：所有光都按同一个 PSF 摊开，`lens(a·x) = a·lens(x)`。"只有超过阈值的光才发光"不是物理。
2. **能量守恒**：光只被搬运、不被创造；总能量 ≤ 输入（差额 = 散射到画面外的光，ε = 0.4 时 720p 约 1.6%，0.5 时约 2.0%）。
3. **逐通道**：轴向色差就是各通道核宽不同，不需要单独叠加"镶边"。

### 4.3 为什么辉光只出现在暗处，而盘面不会被点亮

关键在幅度：长尾只带走 ε 的能量，又摊在很大面积上，每个像素分到的很少。

- **盘面上**：散射进来的光 ≈ ε × 邻域平均亮度，同时自身散出 ε 份——成片的亮区内部两者抵消，盘面保持原样，
  只是对比度按 `(1 − ε)` 轻微下降（柔光镜的真实效果）；
- **黑色天空、黑洞阴影上**：背景 ≈ 0，同样一点散射光相对变化极大，辉光在这里显现。

即：**辉光"像一层附加在高光周围的光"是对比度的结果，不需要阈值，也不需要特殊的合成方式（如取 max）。**

### 4.4 实测（720p，视频构图：`--pov 0 -35 3 --fov 34 --v2_camera_roll 12.5`）

| ε | 总能量比 | 盘面平均变化 | 盘面 p99 变化 | 暗区辉光峰值 | 观感 |
|---|---|---|---|---|---|
| 0.03 | 0.999× | 0.6 灰阶 | 1.8 灰阶 | 12 灰阶 | 与无镜头效果几乎无差别（好镜头） |
| 0.1 | 0.996× | 2.0 | 4.9 | 36 | 同上 |
| 0.2 | 0.992× | 4.0 | 9.9 | 63 | 阴影里出现淡光晕 |
| 0.3 | 0.988× | 6.1 | 14.8 | 85 | 光晕可辨 |
| 0.4 | 0.984× | 8.3 | 20.1 | 103 | 光晕清楚、盘面略朦胧 |
| **0.5（默认）** | 0.980× | 10.6 | 26.4 | 119 | 曝光补偿 0 时整体像蒙了一层雾 |

上表测于白平衡 5000 K、曝光补偿 0（v1.0 旧模型）。v1.1 起默认曝光补偿 +1.5 档：内盘约 2% 的像素烧白，散射光
随之增强，阴影内辉光约为补偿 0 时的 2 倍（§5），0.5 的眩光不再显得发雾，因此默认从 0.4 提到 0.5。
散射进来的光在盘面上的纹理度（12 px 高频残差 / 均值）恒为 5.4%——平滑光晕；盘面"变化"主要是自身散出光
造成的对比度下降，而不是被点亮。

### 4.5 不做的事

- **不模拟**衍射星芒、鬼影、变形镜头横向光条。
- **传感器溢出（blooming）**：超过饱和值的电荷溢到邻近像素，是另一种物理辉光。曝光补偿 +1.5 档时约 1–2%
  的盘区像素越过白点，目前由 ACES 软肩部压缩，未实现溢出；若需要更强的"烧白"晕染可再引入（只作用于超出
  饱和值的光，能量守恒）。

## 5. 传感器：曝光

- **自动曝光**：把盘区亮度（`L > 1e-4`）的 99.9 百分位映射到 0.9，再乘曝光补偿：
  `exposure = 0.9 / p99.9(L_disk) · 2^EV`（`--v2_exposure_ev`，默认 +1.5 档）。只看盘，不看天空（星点不影响曝光）。
- **为什么要补偿**：EV = 0 时画面没有任何像素越过白点，最亮处只到浅金；发光体的视觉线索是"最亮处烧白、
  周围晕开、暗处有辉光"，缺了它盘面像被照亮的固体（"大理石"）。实测（360p、超采样 2，视频构图，
  白平衡 4500 K、眩光 0.5；阴影内辉光为黑洞阴影像素的 LDR 均值，全部来自镜头散射）：

  | 曝光补偿 | 盘区越过白点（LDR > 0.95） | 阴影内辉光 | 亮区饱和度 | 观感 |
  |---|---|---|---|---|
  | 0 | 0% | 0.18 | 0.15 | 浅金、无发光感 |
  | **+1.5（默认）** | 1.8% | 0.37 | 0.26 | 内盘烧白、阴影里有明显辉光，类《星际穿越》 |

  远景（`--pov 0 -60 8 --fov 30`）+1.5 档时为 1.7% / 0.39，与视频构图一致。

- **视频**：首帧计算后锁定曝光（已含补偿），避免逐帧亮度跳变；断点续传时从进度文件恢复同一曝光。
- **运镜视频（测光 + 平滑）**：运镜路径中画面亮度跨约 7 档，锁定曝光无法兼顾。正式渲染前沿路径每 0.5 s 以
  128×72 测光，得到"让盘区 p99.9 回到首帧水平需要补偿的档数" a(t)，高斯平滑（σ = 1.5 s）后部分补偿：
  `exposure_f = E₀ · 2^{EV + clip(k·ā(t_f), −0.9, +1.1)}`，E₀ 为首帧自动曝光（不含补偿），k = 0.6。
  k < 1 保留"入云变亮、盘底变暗"的明暗变化，又不至于全白或全黑。参数在路径文件的 `exposure` 块中。
- **淡入淡出**：运镜视频首尾在 sRGB 编码值上乘 `α = sstep(min(t/T_in, 1, (T − t)/T_out))`（默认 2 s / 3 s），
  属于剪辑操作，不改变曝光。
- **饱和**：没有硬截断；高光的压缩交给 §6 的色调映射（类似胶片的软肩部）。
- 镜头 PSF 在数学上位于曝光之前；曝光是全局缩放、与线性卷积可交换，实现上先曝光后卷积，结果相同。

## 6. ISP：从 HDR 到显示值

| 步骤 | 公式 / 做法 | 默认 |
|---|---|---|
| 白平衡 | von Kries 对角增益 `gain_c = 1/rgb_c(T_wb)`：色温为 `T_wb` 的黑体显示为白色（`--v2_white_balance`） | 4500 K |
| 色调映射 | 保色度 ACES：只对亮度 `L` 做 ACES 曲线 `A(L) = L(2.51L + 0.03)/(L(2.43L + 0.59) + 0.14)`，RGB 等比缩放；超出色域的通道按比例收回，并按 `(max − 1)·0.12`（上限 0.25）向白混合。胶片响应 m（`--v2_film_response`）把它与逐通道 ACES `(A(R), A(G), A(B))` 线性混合：`y = (1 − m)·T_chroma + m·T_channel` | white_blend 0.12，m = 0 |
| 饱和度 | 围绕 BT.709 亮度缩放色差 | 1.0（不变） |
| 编码 | sRGB（IEC 61966-2-1），量化为 8-bit | — |

**白平衡与颜色**：盘面主体 3000–5000 K。白平衡 5000 K（参考实现）时盘面整体偏暖黄；4500 K 时为暖金，最热处为白；
4000 K 偏冷发白（统一气体模型去掉了温度偏低的烟雾层后尤其明显，亮区饱和度只有 4500 K 时的一半）：

| 白平衡 | 盘面平均 sRGB（v1.0 旧模型） | B/R | G/R | 亮区饱和度（v1.1，曝光补偿 0） |
|---|---|---|---|---|
| 5000 K | (69, 54, 36) | 0.53 | 0.78 | 0.22 |
| **4500 K（默认）** | (67, 54, 39) | 0.59 | 0.82 | 0.14 |
| 4000 K | (64, 55, 44) | 0.68 | 0.86 | 0.07 |

色温上限 `T_cap`（§2.3）默认跟随白平衡色温，保证白平衡怎么调，最亮处都止于白色。

**胶片响应（`--v2_film_response`）**：胶片的三层乳剂（数码传感器的 R/G/B 光电位）各有一条特性曲线、各自饱和。
强通道先进入肩部，弱通道还在增长，于是同一颜色越亮饱和度越低，最亮处趋近白色。保色度 ACES 只压亮度、色度不变，
所以最亮处止于浅金，即使曝光补偿加到 +2 档也几乎不烧白（盘区亮度 > 0.9 的像素 0–3%）。m = 1 时三个通道各自过
ACES 曲线，高光沿"通往白色的路径"变淡；代价是 ACES 趾部逐通道拉对比，暗部饱和度略升（暗部更浓、云缝更有层次）。
m = 0（默认）与引入该参数前逐位一致。

实测（`scenes/lensing_bend` 构图，1080p，+1.5 档、8000 K、眩光 0.25；L 为线性亮度）：

| 胶片响应 | 暗部（L 0.01–0.08）饱和度 | 中间调（L 0.2–0.7）饱和度 | 亮部（L > 0.9）占比 / 饱和度 |
|---|---|---|---|
| 0（保色度） | 0.59 | 0.41 | 0.0% / — |
| 1（逐通道） | 0.76 | 0.34 | 1.3% / 0.03 |
| 《星际穿越》截图 | 0.23 | 0.41 | 28.5% / 0.13 |

截图的大片烧白与灰色暗部来自场景（更近、更多近处高温盘面）与电影调色，不是色调映射能补的；
原型中试过"红感层趾部提前"（暗部偏青）与"只在肩部逐通道饱和"，前者让暗部更棕、后者画面发灰且到不了白，均已否决。

白平衡是逐通道增益，镜头 PSF 是逐通道线性卷积，两者可交换，因此实现上白平衡放在 PSF 之前，与
"先镜头、后 ISP"的物理顺序等价。

## 8. 调参指南：症状 → 层 → 参数

| 症状 | 所在层 | 调什么 |
|---|---|---|
| 整体偏黄 / 偏冷 / 惨白 | ⑥ ISP | `--v2_white_balance`（调低更白、调高更暖） |
| 最亮处偏蓝 | ② 辐射 | 色温上限是否跟随白平衡（默认跟随） |
| 左右明暗差太大 / 太小 | ② 辐射 | `--v2_doppler_lum`（并同步 `--v2_doppler_color`） |
| 外盘太暗 | ② 辐射 | `--v2_lum_temp_scale` |
| 没有发光感、像"大理石" | ④ 传感器 | `--v2_exposure_ev`（先让最亮处烧白），再看 `--v2_lens_glare` |
| 辉光太弱 / 太强、画面发雾 | ⑤ 镜头 | `--v2_lens_glare`（辉光与对比度是同一个旋钮的两面） |
| 盘面结构太碎 / 太平 | ① 结构 | `--v2_core_contrast`；细纹强弱由 `core_oct_gain`（内部，默认 0.6） |
| 斜看（透镜瀑布）一片平滑、没有团块与缝 | ② 辐射 + ① 结构 | `--v2_temp_density_coupling 0.25` + `--v2_core_floor 0`：盘光学厚时亮度只取决于温度，加大 `--v2_core_contrast` 会饱和 |
| 大气太浓 / 太淡、云团太碎 | ① 结构 | `--v2_atm_frac`、`--v2_atm_height`、`--v2_atm_fine` |
| 贴盘面时近处云层是一片均匀的雾 | ② 辐射 | `--v2_temp_turb`（0.1 起；视频贴盘帧耗时约 2.4 倍） |
| 整体太亮 / 太暗 | ④ 传感器 | `--v2_exposure_ev`；只想调星空用 `--v2_sky_gain` |
| 锯齿、颗粒 | 求解精度 | `--v2_supersample`、`--v2_opt` |

颜色问题的诊断顺序：先在 HDR 域逐级打印各阶段的 R:G:B 比例（场景光 → 镜头 → 白平衡 → 色调映射），
看是哪一步改了色相，再调那一层。

## 9. 设计原则与教训：bloom 事件（2026-10-03）

旧版（参考实现）的镜头效果是"阈值 bloom + 镶边"：

```
src = x · max(L − 0.3, 0)/L
out = x + 4 · Σ_k w_k · Blur(src, r_k)        r_k ∈ {H/120, H/25, H/7}，复制边缘补边
out += 0.4 · ring(max(L_out − 0.7, 0)) · (0.3, 0.45, 1.0)
```

现象：辉光把后面的盘面点亮、强度过大。逐层量化后发现它在三处违反 §4.2 的镜头性质：

| 问题 | 实测 |
|---|---|
| **造光**：提取的光不从原处扣除，再乘 4 加回 | 散射光 / 提取光 = 4.00×；整图能量 th0.3 时 1.706× |
| **窄核复制纹理**：6 px（720p）核占 25% 能量 × 增益 4 = 盘面纹理以 100% 强度再叠一层 | 该分量在盘面上的纹理度 32–39%（宽核 0.7%） |
| **阈值落在盘面亮度分布中间**：0.3 远低于曝光约定（p99.9 → 0.9）下盘面的亮度范围 | 约 1/4 盘面像素被当高光；盘面中间调 1.36×、亮带 1.94× |
| **边缘补边造光**：复制边缘像素 | 测试图能量 1.41× |
| **镜头效果互相喂**：镶边阈值读 bloom 之后的亮度 | bloom 开关使镶边差最大 B +0.34 |

过程中依次试过：按亮度扣阈值（只修色相）、提高阈值（只减少提取量）、能量守恒的阈值版（亮带和光子环被
抽走 12–44% 的光而变暗）、宽核相加（仍造光）、取 max 合成（非物理、交界有硬边）。每一种都在"错误的模型"上
打补丁。最终回到第一性原理——镜头 = 线性、能量守恒、作用于全部光的 PSF——问题自然消失：

| | 旧版（th0.3 g4 + 镶边） | 镜头 PSF ε = 0.4 |
|---|---|---|
| 总能量比 | 1.712× | 0.984× |
| 盘面平均变化 | +20.7 灰阶（被点亮） | 8.3 灰阶（对比度下降为主） |
| 暗区辉光峰值 | 194 灰阶 | 103 灰阶 |

**教训**：

1. 后处理效果先问"它模拟的是什么物理器件"，再按那个器件的性质（线性？守恒？作用于谁？）实现。
2. 参数调不好时，先怀疑模型，再怀疑参数。
3. 量化要分层：在 HDR 域对每一步做"输出 − 输入"，区分"散射进来的光"和"自身散出的光"，再看输出域。

旧链保留为 `lens_model="legacy"`（原用于对照参考实现，参考实现与对比脚本已于 2026-10-04 删除），取旧值时与改动前逐位一致。
