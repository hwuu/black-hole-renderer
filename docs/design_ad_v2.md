## 1. 问题陈述

V1 吸积盘是零厚度倾斜平面加程序纹理，存在三个问题：

- **P1 无体积感**：纹理贴在几何平面上，看不到半透明层与盘面上方的云雾结构。
- **P2 卷绕**：静态纹理随开普勒差速旋转（内圈快、外圈慢），时间越长结构被拉得越
  同心化，螺旋倾角单调下降，最终退化为同心圆。
- **P3 颜色与亮度缺乏物理依据**：经验颜色映射与多普勒修正导致冷暖、明暗关系难以
  解释与调校。

v2.0–v2.2 曾用预烘焙贴图缓解 P1，但贴图只有极坐标两个维度、缺少竖直结构，且烘焙
阶段就引入同心弧，P1 与 P2 均未解决。

## 2. 分析与选型

- **体积密度场加辐射转移**：把盘建模为三维半透明介质，体积感来自沿光线的积分。
  这直接回应 P1。
- **刚体环平流**：把半径取对数后分带，带内以带中心角速度整体旋转（刚体），带间
  平滑混合；结构种子有有限寿命并交叉淡化。任意时长下都不产生差速剪切，回应 P2。
- **物理亮度与颜色**：相对论频移后的观测谱仍是温度 `g·T` 的黑体（`g` 为频移
  因子），亮度取可见光波段亮度，颜色取黑体色度，回应 P3；偏离物理的取值全部整理
  为显式的视觉参数。
- **统一气体模型**（v2.4）：盘面与其上方的大气是同一团气体——同一柱密度、同一湍流场、
  同一条灰大气温度规律、同一个 κ；v2.3 中"核心 + 烟雾层 + 尘埃"三部分各算各的、彼此不相关
  （烟雾像贴在盘上的斑块），已删除。
- **验收方式**：v2.3 以参考实现为基准逐像素移植；v2.4 先在原型中定稿观感，再逐步移植进源码，
  每步与原型逐位一致（见 `plans/v2_unified_gas_plan.md` §11）。

## 3. 方案设计

### 3.1 模块分层与数据流

```
+--------------------+     +----------------------+     +----------------------+
| advection.py       |---->| taichi_impl.py       |---->| taichi_render.py     |
| rigid-ring phases  |     | volume density field |     | geodesic march       |
| (CPU float64)      |     | density_I            |     | emission-absorption  |
+--------------------+     +----------------------+     +----------------------+
          ^                           ^                            |
          |                           |                            v
+--------------------+     +----------------------+     +----------------------+
| render.py          |     | noise_ti.py          |     | postfx.py            |
| frame time, camera |     | gradient / cascade   |     | lens PSF, WB,        |
| exposure lock      |     | physical_fields.py   |     | ACES, sRGB encode    |
+--------------------+     +----------------------+     +----------------------+
```

数据流：`render.py` 给出帧的物理时间 `t` 与相机 → `advection.py` 在 CPU 上用
float64 计算每条带的转角、种子进度与周期索引并上传（GPU 上没有 float64，长视频中
相位误差会破坏平流的连续性）→ 渲染核沿测地线步进，在每个步长中点查询三维密度 →
累积线性高动态范围（HDR）亮度 → `postfx.py` 曝光与显示编码。

| 模块 | 职责 |
|------|------|
| `params.py` | 盘几何参数与体积模型参数（统一气体模型的全部取值） |
| `physical_fields.py` | Page–Thorne 薄盘温度与峰值推导、Shakura–Sunyaev 外区标高与柱密度（NumPy 参考实现） |
| `relativity.py` | 频移因子的 NumPy 参考实现与严格广义相对论对照 |
| `palette.py` | CIE 黑体色度与亮度查找表、白平衡增益 |
| `noise_ti.py` | 梯度噪声、值噪声、乘性级联、分形叠加（fBm） |
| `shear_cascade.py` | 主云剪切级联的各八度几何（周期 / 剪切 / 拉伸）解析构造与 NumPy 参考 |
| `gas_unified.py` | 统一气体模型竖直剖面、散射反照率、柱密度的 NumPy 参考 |
| `advection.py` | 刚体环带常量表与每帧相位表 |
| `taichi_impl.py` | 统一气体密度场、Taichi 端频移、光行时间相位换算、噪声与吸收系数标定 |
| `taichi_render.py` | 渲染器：主光追核、超采样、曝光 |
| `postfx.py` | 成像链：镜头 PSF、白平衡、色调映射、编码（见 [`imaging_model.md`](imaging_model.md)） |

### 3.2 结构场：盘"长什么样"

| 分量 | 公式 | 说明 |
|------|------|------|
| 标高 | `H(r) = HR_REF·r·(r/10)^(1/8)·(f/f_10)^(3/20)`，`f = 1 − sqrt(r_in/r)` | Shakura–Sunyaev 外区（气压主导、Kramers 不透明度） |
| 柱密度 | `Σ(r) = (r/10)^(−3/4)·(f/f_10)^(7/10)·外缘截断·LN(σ_L·n_L)` | 叠加大尺度低频对数正态明暗 |
| 表面 | `H_s = H·(1 − SURF_NOISE + SURF_NOISE·softsat(tn))` | 噪声调制的云顶轮廓 |
| 湍流 | `c`：对数极坐标剪切级联 `softplus(con·Σ_k ln(1 + 0.1·γ^k·n_k))`，`ĉ = c/⟨c⟩` | 各八度噪声格按开普勒剪切取形：长宽比由 10 几何插值到 2.5，长轴略向拖尾倾斜（倾角系数 0.01） |
| 核心 | `ρ_c = cfac·Σ/(√(2π)·H_s)·exp(−z²/2H_s²)`，`cfac = f + (1 − f)·ĉ` | 致密盘面（等温静力平衡），`f = core_floor` 默认 0.15 |
| 大气 | `ρ_a = A·Σ·ĉ·cov(ĉ)·m(n)·exp(−|z|/H_a)/(2H_a)` | 同一团气体被加热上浮的稀薄尾巴；`cov(ĉ)` 软阈值使湍流稀处出现空隙；`m(n) = exp(σ_a·n − σ_a²/2)` 为小尺度起伏（保均值），使大气随高度与盘面去相关 |

大气参数：`A = atm_frac`（0.15，大气柱 / 核心柱）、`H_a = atm_height·r`（0.01，约为核心标高 3 倍）、截断高度
`atm_extent·H_a`（5）、覆盖阈值 `atm_cov_c0 / atm_cov_soft`（1.0 / 0.3）、`σ_a = atm_fine_sigma`（0.5）、竖直频率
`atm_fine_fz`（2）。r = 22 处大气竖直光学深度约 0.06、约一半面积是空隙；相机在盘内时周围是金色云雾。

**盘厚缩放**：核心标高乘 `thickness_scale`（默认 1/9，H/r ≈ 0.003，接近物理量级；1 为预设 M 的视觉厚度），
核心区盘内步长同步缩放；大气标高不随它缩放。柱密度与光学深度不随厚度变化，俯视外观基本不变；贴近盘面
观察时视线可越过外盘看到内盘（见 [`plans/v2_edge_on_plan.md`](plans/v2_edge_on_plan.md)）。

**湍流的形状**：开普勒剪切率 `q = −dlnΩ/dlnr = 3/2` 与半径无关，湍流团块被剪切拉长的比例也与半径无关，
所以噪声格在 `ln r` 中等距、各半径形状相同；大尺度结构存活更久、被拉得更长（AR ≈ 1 + q·Ω·τ）。
逐八度增益 `core_oct_gain` 默认 0.6（比 Kolmogorov 的 3^(−1/3) ≈ 0.69 略陡，小尺度条纹更弱，避免满盘锐利
细纹造成"大理石"质感）。刚体环带接缝修复（`band_seam_fix`）：带边界随 φ 起伏，带间保方差混合
`c = m + α·Σw_k(c_k − m)/√Σw_k²`，`α = core_contrast`（默认 0.8）。厚度扰动 `tn` 仍用乘性级联
（`kt_i / nphi_t / lt0_i / con_t / az_stretch_t`）。

所有噪声（`n_L` 与大气小尺度起伏 `n`）在标定阶段归一到单位方差，因为 `σ_L`、`σ_a` 都按单位方差定义。
噪声坐标使用刚体环平流的流坐标 `φ0 = φ − Ω_b·(t − Δt) − φ_b`，其中 `Δt` 为光行时间延迟、`Ω_b` 为带中心
角速度、`φ_b` 为每带随机相位偏移。

### 3.3 辐射转移：盘"发出什么光"

- **温度**：Page–Thorne 相对论薄盘温度 `T(r)`，峰值温度由黑洞质量与吸积率经绝对
  通量推导；核心与大气共用一条灰大气竖直温度规律 `T⁴ = ¾T_eff⁴(τ_z + ⅔)`（带温度上限），
  τ_z 为上方柱（核心 erfc + 大气指数）的光学深度，从中面到大气顶连续下降；叠加湍流发热起伏。
- **吸收与散射**：消光 `α = κ·(ab_c + ab_a)`；大气的散射反照率由密度决定
  `ω = 1/(1 + q·ρ_a/ρ_mid)`（Kramers 吸收 ∝ ρ、电子散射与 ρ 无关，`q = abs_scatter_ratio` 默认 20），
  稀薄大气以散射为主。`κ` 按核心 + 大气总柱在 `r ∈ [5.5, 6.5]` 处标定为 `tau_i`（默认 1.84）。
- **发射**：`j = em_c·S_c + (1 − ω)·ab_a·S_c + ω·ab_a·(1 − e^{−τ_c})·j_s·S_disk`。前两项为核心与大气的
  热发射（温度同为灰大气温度 `T·tf`）；第三项为大气对下方盘面光的单次散射：入射场取下方核心层的发射
  `(1 − e^{−τ_c})·S_disk`（τ_c = κ·cfac·Σ），`j_s = scatter_j` 默认 0.5（半个天空）。散射光颜色就是当地
  盘面颜色，所以大气是金色。源函数 `S(T, g) = Y(s·g^{s_L·k}·T)/Y(s·T_peak)·χ(T·g^s_C)`。
- **亮度温度倍率**：上式中的 `s`（`lum_temp_scale`，默认 1.25，1 为物理）只作用于亮度、不作用于色度。
  4500 K 盘在可见光处于 Wien 段，亮度对温度的对数斜率 `dlnY/dlnT ≈ 5.7`，外盘几乎全黑；`s = 1.25` 使斜率降到
  4.6，r = 20 处亮度从峰值的 0.4% 升到 1.2%，贴盘面视角下外盘可见，纹理基本保留。`s` 增大会同比减弱频移
  造成的明暗不对称，因此多普勒亮度指数乘以补偿系数 `k = [dlnY/dlnT](T_peak) / [dlnY/dlnT](s·T_peak)`
  （`s = 1` 时 `k = 1`）。这是艺术夸张，与参考实现对比时取 `s = 1`（见
  [`plans/v2_edge_on_plan.md`](plans/v2_edge_on_plan.md) §9）。
- **段内精确解**：每个积分段 `ΔI = T·(j/α)·(1 − e^(−αΔs))`，透射率
  `T ← T·e^(−αΔs)`；光学薄极限退化为 `T·j·Δs`。
- **像素构成**：盘发射 `Σ T·ΔI` 与透射后的天空 `T_end·I_sky` 分两路累积。每个
  段先积分、再判断光线是否落入事件视界，因此落入视界前穿过盘的发射得以保留
  （光子环下半部正来自这部分光线）。
- **频移**：`g = g_grav / (γ(1 − β·cosθ_loc))`，其中 `β = sqrt(M/(r − 2M))` 为
  本地静止观者测得的圆轨道速度，`θ_loc` 为光子在本地静止观者标架下与轨道速度的
  夹角；相机同样使用静止观者本地标架。亮度与色度各带一个显式的强度指数
  （1 为物理值）：亮度指数 `doppler_lum` 默认 0.25、色度指数 `doppler_color` 默认 0.75（预设 M 定稿
  0.55 / 1.5；两者同比减弱，CLI `--v2_doppler_lum` / `--v2_doppler_color`）。色度温度封顶到白平衡色温
  （默认 4500 K）：`χ(clamp(T·g^q, T_floor, T_WB))`，最亮处止于白色，不越过白点变蓝；下限 `T_floor`
  （`color_temp_floor_K`，CLI `--v2_color_floor`）默认 0 不启用，设为 2500–3000 K 时冷区固定为暗金、
  只靠亮度变暗。实测画面"发红"主要来自 bloom 逐通道扣阈值（见 §3.4），下限作用很弱。

### 3.4 后处理与视频

- **曝光**：把盘区亮度（`L > 1e-4`）的 99.9 百分位映射到 0.9，再乘曝光补偿 `2^EV`（`exposure_ev`，
  CLI `--v2_exposure_ev`，默认 +1.5 档）。EV = 0 时画面无过曝、最亮处只到浅金，缺少"发光"感；+1.5 档使
  内盘最亮约 1–2% 的像素烧白，镜头辉光随之增强。天空以独立参数控制亮度，只有盘参与曝光计算。
  视频首帧计算后锁定曝光（已含补偿），避免逐帧亮度跳变。
- **天空**：天空盒图像从 sRGB 编码解码为线性光、双线性采样；合成时
  `x = 曝光·盘 + sky_gain·天空`，随后整体进入后处理（星点同样经过镜头 PSF）。
- **后处理链**（按真实相机建模，原理、公式与实测见 [`imaging_model.md`](imaging_model.md)）：白平衡（von Kries，
  默认 4500 K）→ 镜头 PSF（能量守恒长尾眩光 ε = 0.5 + 轴向色差）→ 横向色差 → 保色度 ACES → sRGB。
  参考实现的"阈值 bloom + 镶边"会额外加光（散射光为提取光的 4 倍）并把盘面纹理复制叠加，导致辉光后面的
  盘面被点亮，已替换；保留为 `lens_model="legacy"` 供对照（见 `imaging_model.md` §9）。
- **视频**：帧时间 `t = 2000 + frame·dt`，`dt = P(r_in)/(v2_orbit_seconds·fps)`
  （`P` 为内缘轨道周期）；相机支持环绕模式。
- **超采样**：以超采样倍率 N 的 `N×N` 倍内部分辨率积分后盒式下采样，配合首步随机偏移
  构成蒙特卡洛体积积分，消除采样网格的规则条纹。
- **优化级别**：`--v2_opt 0–3`，级别 1 与级别 0 输出逐位一致，级别 2、3 放大盘内步长（光子环
  附近的光线保持原步长）；定义、门槛与实测见 [`plans/v2_performance_plan.md`](plans/v2_performance_plan.md)。
- **姿态与旋转方向**：盘面姿态由俯仰（绕世界 x 轴）与滚转（绕世界 y 轴）两个角确定；
  另有相机滚转（`camera_roll_deg`，CLI `--v2_camera_roll`）：相机绕自身光轴旋转 ρ，
  基向量 `r' = cos ρ·r − sin ρ·u`、`u' = sin ρ·r + cos ρ·u`，整个画面（盘与星空）一起倾斜，
  +12.5° 为画面左低右高；在画面系中生效，环绕过程中倾角恒定（盘滚转固定在世界系，
  环绕时画面倾角会漂移：起始 ρ° → 环绕 90° 时变为开口角变化 → 180° 时反向）；
  相机位于 y–z 平面内时，"盘俯仰 θ、相机仰角 e"与"盘不俯仰、相机仰角 e + θ"两种配置
  逐像素一致（单测保护）。旋转方向由 `DiskV2Params.disk_spin`（±1）给出，刚体环平流与
  多普勒频移共用同一符号（单测保护）。

## 5. 非目标

Kerr（自旋）度规；磁流体力学模拟；交互模式接入 V2；V1 路径的任何行为改变。
